# Synthetic proteomics fixtures

These small redistributable synthetic software fixtures contain no real specimens, individuals or database sequences. `design.json` declares eight independent biological samples, four per condition, with two batches balanced across conditions. The integer seed 1729 identifies the fixture; all values are explicit powers of two, with no random draw.

`intensities.json` contains the planted CHANGED protein (mean log2 difference 4), balanced BATCH protein (difference 0), two variable null proteins, seven zero-variance median anchors, one low-peptide protein, one insufficiently observed protein, one decoy and one contaminant. Missing values are null, never zero. Every sample's eligible log2 median is 10; median-normalization offsets are zero. Decoy and contaminant rows remain visible and are excluded from sample normalization/QC totals. Low-peptide rows remain in sample totals but cannot be hits.

For CHANGED, the two log2 groups are [10,11,10,11] and [14,15,14,15]. Means are 10.5 and 14.5; sample variances are 1/3, standard error sqrt(1/6), t=sqrt(96), df=6. For u=sqrt(16/17), the two-sided tail is `1-(15*u-10*u**3+3*u**5)/8`. Four proteins are tested, so the planted protein's BH q is four times that p; all three remaining tested proteins have p=q=1. Other rows are explicitly untestable, with null significance rather than false.

`pack.json` freezes the complete specification and hashes the synthetic design before intensity admission. `association.json` is a declared synthetic statistical-evidence fixture, not an independent experiment or review. `expected.json` is the deterministic reference result. `negative-cases.json` lists all 30 labelled refusal bundles and their reasons; each nearby named JSON file is a complete synthetic pack or a synthetic input for one. Tests run every negative through the Python entry point and CLI and compare numerical results with the hand calculations above.

Run `python3 scripts/validate_proteomics_pack.py examples/workflow-proteomics-differential-abundance/pack.json` from the repository. It prints JSON and writes nothing. Stage/field/limit details are in `authored-skills/workflow-proteomics-differential-abundance/references/stages.md`. Software acceptance does not establish biological, causal, physical or clinical validity; coordinator-owned independent review remains unavailable in these fixtures.
