# Synthetic Bland–Altman fixtures

All files in this directory are redistributable synthetic fixtures, never measurements of real units or evidence of method suitability. The primary accepting bundle is pack.json; interval-pack.json and log-pack.json exercise the 30-unit interval edge and natural-log differences. Every bundle contains hashed immutable rule, pair and report identities. Run python3 scripts/validate_bland_altman_agreement_pack.py examples/workflow-bland-altman-agreement/pack.json from the repository root; acceptance is JSON on stdout, refusal is JSON with finding on stderr and exit 2. The validator writes nothing.

For the tiny synthetic table, pair means are 10, 20, 30, 40, 50, 60; differences A - B are 0, 1, 2, 2, 3, 4. Their sum is 12, centered sum of squares is 10, bias is 2, and sample SD is sqrt(2). Limits are 2 plus/minus 1.96sqrt(2). Sxx is 1750, Sxy is 130, slope is 13/175, residual sum of squares is 12/35 and t squared is 338/3 on 4 degrees of freedom. All CIs are unavailable below 30. A seventh frozen unit has a missing A method: it remains explicitly unavailable and is excluded, never imputed as zero. The normality moment screen passes; proportional bias is detected and retained.

The 30-unit synthetic fixture repeats the six differences five times at distinct means. Its bias is 2, sample SD sqrt(50/29), bias SE s/sqrt(30), and each limit SE s*sqrt(3/30). The t multiplier on 29 degrees of freedom is approximately 2.045229642132703. The log fixture exponentiates one tenth of each original method value; recomputation must yield bias 0.2 and SD sqrt(2)/10 on natural-log scale. Its tiny floating skewness is compared relatively, never using an absolute tolerance.

expected.json and prefixed expected files contain deterministic synthetic reference output. Hand-derived checks and all negative-cases.json mutations run through tests/test_workflow_ba_pack.py. Refusals cover correlation as agreement (including text), wrong log scale, undeclared repeated measurements, missing or premature intervals, ignored proportional bias, silently dropped unpaired units, post-outcome bound changes, unfrozen rules and claims of interchangeability, clinical acceptability, equivalence, method validity, causality, physical validity or truth. No case grants independent review. The validator retains no output files, so a concurrent call or interruption leaves these fixtures unchanged.
