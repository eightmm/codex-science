# Synthetic absorbance fixture

Every file here is a redistributable synthetic fixture, never a measured biological sample or a suitability assessment. pack.json is the accepting entry point. rules.json is hashed before readings.json is admitted. report.json records the unreviewed reference quantities; expected.json is the test expectation. negative-cases.json declares one mutation and expected finding per seeded defect. Tests materialize each independently with fresh hashes and preserve distinct refusal reasons.

Invoke python3 scripts/validate_nucleic_acid_quant_purity_pack.py examples/workflow-nucleic-acid-quant-purity/pack.json from the repository root. It prints nuc-result-v1 JSON and writes no files. Refusals, including argument errors, are JSON on stderr with finding and exit 2; help is plain stdout usage with exit 0. Concurrent calls leave the same inputs unchanged; interruption can truncate stdout, so capture output atomically outside the bundle.
