# Synthetic growth-curve fixtures

All files in this directory are redistributable synthetic fixtures. They contain no measured biological data. Run `python3 scripts/validate_growth_curve_pack.py examples/workflow-growth-curve/pack.json` from the repository root. It accepts exactly one argument, writes nothing, and emits JSON on stdout; refusals emit labelled JSON with finding on stderr and exit 2.

`protocol.json` freezes the model-free maximum log-OD slope method, three-point windows, subtraction, identities and QC limits. `data.json` contains two stable blank wells, two noiseless logistic wells, a saturated well and a noisy well with declared upstream non-convergence. `report.json` is an unreviewed expected arithmetic artifact; `evidence.json` explicitly labels its record computed, never positive biological evidence. `pack.json` binds these files by raw-byte hashes. `expected.json` records independent hand-derived numbers and generator parameters. `negative-cases.json` describes deterministic edits that the focused test materializes in temporary directories and rehashes before validation. Every negative case retains its distinct expected finding.

The logistic generator has K=1, rate=log(2), midpoint=2. Finite-window model-free rate differs from the generator's logistic rate by design. For A1 corrected OD at times 0..4 is 1/5, 1/3, 1/2, 2/3, 4/5: slope log(2.5)/2, tangent lag -35/27, maximum 4/5, trapezoidal AUC 2, doubling 2*log(2)/log(2.5). A2 scales OD by 3/4: capacity mean 0.7 with SE 0.1 and AUC mean 1.75 with SE 0.25. Both reliable wells are technical wells from one biological unit. Zero variance leaves the corresponding standard error unavailable. Saturated A3 and noisy non-converged A4 remain visible and excluded.

No fixture establishes fitness, resistance, drug effect, mechanism, causality or clinical relevance. Review remains unavailable and coordinator-owned. Numerical agreement is software evidence only. Concurrent or interrupted validator calls leave these files unchanged and may leave incomplete stdout only.
