# Synthetic Arrhenius fixtures

Every table and artifact here is a redistributable synthetic fixture. No rates are experimental observations. Run python3 scripts/validate_arrhenius_rate_fit_pack.py examples/workflow-arrhenius-rate-fit/pack.json from the repository root. The validator writes nothing and returns unreviewed arithmetic only.

The main pack.json uses rules.json, rates.json and report.json. The noiseless-pack.json uses noiseless-prefixed counterparts. Each pack contains immutable relative path-plus-hash identities. Expected artifacts are expected.json and noiseless-expected.json. Negative-cases.json lists independent fixture mutations and stated findings; tests materialize each in a temporary bundle and refresh the identities.

Both synthetic series have nominal ln A = 4, A = exp(4) s^-1, Ea = 1000 R = 8314.46261815324 J/mol and inverse kelvin temperatures .004, .003, .002, .001. Each temperature has two technical replicates; four distinct temperatures, not eight, enter the regression. The noiseless log rates are 0, 1, 2, 3. Noisy mean log rates are .1, .9, 1.9, 3.1, with two replicate offsets -.2 and +.2 at each temperature. Noise is deterministic and orthogonal to the slope/intercept, not a stochastic simulation or claim of unbiased sampling.

For the noisy synthetic fixture, residuals .1,-.1,-.1,.1 give SSE .04 and df 2. Centered inverse-temperature sum of squares is .000005. Slope SE is sqrt(4000), ln A SE is sqrt(.03), residual standard error is sqrt(.02), and the 95 percent t critical value is 4.30265272974946. Pure error SS .32 with df 4 and lack-of-fit SS .08 with df 2 give F .5 and upper tail p .64. At 400 K, mean ln rate is 1.5 with SE sqrt(.005). Exponentiating its t endpoints gives a geometric-mean-rate interval, never a future-run or lifetime interval. Noiseless pure-error variance is zero, so lack-of-fit stays unavailable.

Seeded defects cover Celsius labels/substitution, zero/negative rates, fitting below the frozen temperature minimum/span, extrapolated predictions, gas-constant unit mismatch, counting replicates as temperatures, post-outcome weighting without an exploratory label, an unfrozen rule declaration, and forbidden mechanism, shelf-life, process-safety, reaction-order, causal, physical-validity, clinical-validity and review-truth wording. Passing software checks establishes no physical validity or independent review.
