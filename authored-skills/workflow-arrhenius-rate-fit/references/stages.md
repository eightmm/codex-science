# Arrhenius stages and local record contract

Every checked-in table, question and expected artifact is a synthetic fixture. This reference constrains offline arithmetic and software acceptance only. It supplies neither observational evidence nor independent review.

## Invocation and immutable identities

Public entry points in codex_science.arrhenius_rate_fit_pack: validate_arrhenius_rate_fit_pack(bundle), compute_arrhenius(rates, rules, weighting=None) and student_t_critical(df, level=0.95). The computation override is a reference-arithmetic option; the bundle validator enforces exploratory labelling against frozen weighting.

```bash
python3 scripts/validate_arrhenius_rate_fit_pack.py examples/workflow-arrhenius-rate-fit/pack.json
```

The CLI accepts exactly one bundle argument, prints JSON on stdout and exits 0 on acceptance. All refusals, including missing, extra and unknown arguments, print JSON with status refused and finding on stderr and exit 2. Help stays plain usage on stdout with exit 0. There is no output option. A second concurrent call reads immutable inputs independently. Interruption leaves every input unchanged and can truncate stdout; durable capture is the coordinator's responsibility. The validator writes no file, ref or record.

Artifact identities are exactly path and sha256: canonical relative POSIX paths within the bundle and lowercase 64-hex SHA-256 of the bytes parsed. The initial pack is identified by its pinned path and computed hash. Absolute artifact paths, traversal, backslashes, noncanonical spellings, symlinked components, special files and unavailable files are refused. Pin the root from the filesystem root by walking each component with directory descriptors, O_DIRECTORY, O_NOFOLLOW and O_NONBLOCK; compare each lstat/fstat identity and retain the whole ancestor device/inode chain and root descriptor. All artifact opens are relative to pinned descriptors, with lstat regular-file checks, O_NONBLOCK/O_NOFOLLOW, fstat identity/size checks, bounded reads and post-read signature checks. Hash bytes actually parsed. Cache bytes and JSON by device/inode so hardlink aliases are initially read and parsed once. Final rechecks reread each distinct inode once, check every alias signature/hash and compare the entire ancestor chain again. A root or ancestor replacement, even preserving the bundle inode, refuses. Failed input bytes are never repaired or deleted.

## Limits and types

Named module limits: MAX_BYTES 67108864 per artifact; MAX_TOTAL_BYTES 268435456 aggregate initial raw bytes across distinct inodes; MAX_NODES 4000000 JSON values per bundle; MAX_ROWS 10000 frozen runs, rate rows and generic JSON entries per container; MAX_TEMPERATURES 128 distinct temperatures; MAX_RECORDS 128 claims, evidence artifacts, total evidence records and citations per claim; MAX_STRING 4096 characters; MAX_DEPTH 32; MAX_NUMBER 1e100 absolute numeric magnitude; MAX_ITERATIONS 10000 beta continued-fraction iterations; QUANTILE_STEPS 96 t-inversion steps. Bounds apply before proportional sets, scans, computation or parsing. Size equality passes; excess refuses before reading. Preparse JSON allowance counts root, commas and nonempty containers with an iterator; punctuation inside strings can conservatively overcount. Bundle allowances are charged once per distinct inode, before parsing new JSON.

Temperature and requested temperature are finite in 1e-6 to 1e6 K; minimum span is finite in 1e-6 to 1e6 K. Rates are finite and strictly positive up to 1e100. Minimum distinct-temperature count is a real int in 4 to MAX_TEMPERATURES. Confidence level is .5 to .999; lack-of-fit alpha is .001 to .5. The fixed gas constant is GAS_CONSTANT 8.31446261815324 J/(mol K), or that value divided by 1000 in kJ/(mol K); relative comparison tolerance is 1e-12 with zero absolute tolerance. Reference arithmetic uses math.fsum and explicit comparisons, never sign products. Every declared integer, including reported counts and df, must be an int, never bool, float or numeric string. All numeric inputs must be finite. JSON refuses duplicate keys at every depth, NaN/Infinity, huge numbers, malformed UTF-8, non-object roots and excessive nesting with labelled ValueError findings. Strings are bounded, nonempty and cannot contain surrogate codepoints. Unknown or missing object fields are refused.

## Pack-local schemas

All six schemas are ordinary domain artifacts, not global schema changes. Each input has schema equal to its name and fixture equal to synthetic fixture. Artifact descriptors are exact path/sha256 objects.

- arr-pack-v1: rules, rates and report identities; evidence list of identities; frozen_rules_sha256 matching rules.sha256; boolean frozen_before_rates_read true. Freeze validation occurs before rate bytes are opened. This declaration cannot independently establish historical order.
- arr-rules-v1: temperature_unit K; nonempty rate_unit; energy_unit J/mol or kJ/mol; gas_constant and gas_constant_unit matching energy units; nonempty runs; replicate_rule mean-log-within-temperature; weighting ordinary-least-squares or replicate-variance; integer minimum_temperatures at least four; minimum_span_kelvin; prediction_temperature_kelvin; extrapolation forbidden; interval_level; lack_of_fit_alpha. Each frozen run is exactly run_id, temperature_kelvin and replicate_id. Run IDs are unique; each temperature/replicate pair is unique. Runs do not contain rates.
- arr-rates-v1: nonempty rows. Each row is exactly run_id, replicate_id, temperature_kelvin, temperature_unit, rate and rate_unit. Every frozen run occurs once, with identical replicate identity and kelvin temperature. Units match the rules; rate must be positive before log transformation. Celsius labels refuse as temperature-unit, and a Celsius number substituted into a frozen kelvin row refuses as temperature-identity. Deliberately false metadata in both frozen rules and rates cannot be detected by arithmetic alone.
- arr-report-v1: rules_sha256; boolean exploratory; weighting; computation; nonempty headline; claims. A changed weighting requires exploratory true and recomputation; retain the original frozen rules and hash. Headline and claim gates run before rate arithmetic so boundary findings are not masked by later numerical errors.
- arr-evidence-v1: records list. Each record is exactly id, kind, result, origin and source. IDs are unique across evidence documents. Kind and result are bounded text. Origin is internal, external, independent or preregistered. Source is a hash-bound identity. Every non-internal source path AND hash must differ from every pack, rule, rate, report and evidence-document identity, refusing hardlink/content aliases. Non-aliasing is not proof of independence.
- arr-result-v1: validator-produced schema, fixture, status arithmetic-only, review unavailable, ordered stages, boolean exploratory, inputs list of path/sha256 identities, computation, claims and limitations. It is unreviewed software output, never a review receipt. Expected.json and noiseless-expected.json wrap computation with the synthetic fixture label; negative-cases.json contains fixture mutations with target, path, value and expected finding.

Computation is exactly status, integer n_runs, integer n_temperatures, temperature_span_kelvin, weighting, rate_unit, energy_unit, temperatures, df, Ea, Ea_se, Ea_interval, ln_A, ln_A_se, ln_A_interval, slope, slope_se, residual_standard_error, t_critical, lack_of_fit and prediction. Status is fitted or unavailable. Each collapsed temperature is exactly temperature_kelvin, integer n_replicates, mean_log_rate and variance_log_rate; sample variance is unavailable for a singleton. Numeric intervals are two-element lower/upper lists. Below minimum count or span, df, every fit parameter/error/interval, residual error, t critical value and lack-of-fit are unavailable. All reported numbers must match reference computation with relative tolerance 1e-9 and zero absolute tolerance, including near-zero values; reported integer fields are validated as real ints before comparison.

Prediction is exactly temperature_kelvin, status, ln_rate, rate, ln_rate_se, ln_rate_interval and rate_interval. Status is inside-range, outside-range or unavailable. Outside-range and unavailable predictions retain unavailable numeric fields. Lack-of-fit is unavailable or exactly F, integer df_numerator, integer df_denominator, p and boolean flag. No unavailable quantity is replaced with zero or a negative finding.

## 02-table-qc

Input: rules and rates path-plus-hash identities. Call the validator's rule and table checks. Output: admitted arr-rates-v1 ordinary artifact with original rows preserved. Stop on duplicate/missing runs, inconsistent units, Celsius substitution, nonpositive/nonfinite rates or changed replicate identities. Never silently drop a failed control. Collapse ln k within each exact declared temperature by its arithmetic mean; its replicate variance is sum squared log deviations divided by count minus one. Technical replicate rows never increase n_temperatures. Trustworthy measurement provenance remains outside software validation.

## 03-fit

Input: admitted rule/rate identities and applied weighting declared in the report. Call compute_arrhenius and student_t_critical through the one-argument CLI. Output: computation within arr-report-v1 and arr-result-v1. Fewer than the frozen minimum distinct temperatures, or span less than the frozen minimum, produces unavailable parameters. Equality passes. Otherwise zero inverse-temperature or collapsed log-rate variance refuses as degenerate-fit.

Let x_i = 1/T_i and y_i be the mean ln k at temperature i. OLS uses unit weights. Only replicate-variance weighting is admitted as an alternative: w_i proportional to n_i/s_i squared, where s_i squared is the sample variance of replicate log rates. Require at least two replicates with strictly positive variance at every temperature. Normalize weights to mean one; refuse nonfinite weights or normalization underflow. Arbitrary supplied weights are not accepted. Estimate weighted xbar and ybar, Sxx = sum w_i times (x_i-xbar) squared, slope b = sum w_i times (x_i-xbar)(y_i-ybar) divided by Sxx, ln A = ybar-b*xbar, and Ea = -R*b. df = number of distinct temperatures minus two. Weighted residual variance is sum w_i residual_i squared divided by df. Residual standard error is its square root in normalized-weight log units. Slope SE = sqrt(variance/Sxx), ln A SE = sqrt(variance*(1/sum w + xbar squared/Sxx)), and Ea SE = R times slope SE. Noiseless nonconstant series may have zero residual error and zero-width intervals; constant collapsed log rates refuse.

Use equal-tail Student t intervals at interval_level with regression df. The stdlib reference evaluates the regularized incomplete beta integral with a bounded continued fraction and inverts the t two-sided tail by bounded bisection over 0 to 1000. Failure is interval-convergence; no normal approximation fallback. These intervals are conditional on log-linear errors and frozen precision assumptions. Estimated replicate variances make WLS intervals approximate rather than exact sampling guarantees.

At requested T, first compare 1/T with the inclusive measured inverse-temperature range. Outside returns outside-range with no estimate or interval; never extrapolate. Inside, mean ln rate is ybar + b*(1/T-xbar). Propagated mean-response SE is sqrt(variance*(1/sum w + (1/T-xbar) squared/Sxx)). Apply the same t critical value to this mean ln rate, then exponentiate the endpoints. The resulting interval describes the geometric mean rate under the log model, not a future run, arithmetic mean rate, lifetime or safety bound. Log rate and interval endpoints must lie within -700 to 700 before exponentiation; failure is prediction-numeric.

A classical pure-error lack-of-fit F is available only for OLS with the same replicate count r greater than one at every temperature and positive pooled pure-error variance. Pure SS sums all squared within-temperature log deviations; pure df = run count minus distinct-temperature count. Lack-of-fit SS = r times unweighted collapsed regression SSE, with regression df. F = (lack-of-fit SS/df)/(pure SS/pure df); p is the upper F tail computed by the same incomplete beta integral. Flag p less than frozen lack_of_fit_alpha. Balanced equality at the alpha threshold does not flag. Unbalanced replicates, WLS, no replicates or zero pure-error variance return unavailable rather than a negative lack-of-fit result. A flag is retained for method review, not silently removed or promoted as physical validity.

## 04-summary

Input: all computation records and original path/hash identities. Call report/reference comparisons. Output: complete arr-report-v1 with run and distinct-temperature denominators, collapsed means/variances, fit or unavailable values, uncertainty and retained lack-of-fit flags. Preserve null/negative results, failed controls, source dependencies, conflicts, rejected alternatives and limitations. Stop scientific interpretation on failed controls; retain arithmetic diagnostics for review. Missing/unavailable evidence never becomes a zero or negative result.

## 05-handoff and claim gate

Input: immutable rule/rate/report/evidence identities, full computations, failures and coordinator records. Call $science-provenance to register ordinary artifacts and separate existing claim-register entries, then $science-review in record, source and method modes. Output: arr-result-v1 plus the coordinator's existing checkpoint and claim register; a later independent receipt is owned by the coordinator. This pack always leaves review unavailable and never grades its own rigor. Preserve failed controls in original input bytes and caller-captured refusal JSON.

Claims are exactly id, kind, status, text and evidence IDs. Kind is descriptive or associational. Status is planned, supported, replicated, suggestive, conflicting, unsupported, withdrawn or unavailable. Empty evidence requires unavailable. Citing ANY unavailable kind or result requires unavailable for every other status, even mixed with observed evidence. Unavailable claims cannot assert supported, replicated, suggestive or significant evidence. Replicated status always refuses because a synthetic fixture cannot establish two independent studies. Every positive status (supported, replicated, suggestive) refuses when any citation's kind OR result denotes review, approval, computation, numerical agreement, truth, physical or clinical validity. Labels do not substitute for evidence.

Conservative case-insensitive English whole-word/prefix wording families: caus*, mechanis*, therap*, clinic*, efficac*, effective*, treat*, cure*, prevent*, recommend*, prescri*, bind*, affinit*, inhibit*, activat*, regulat*, drive/drives/driv*, induc*. Also truth, physical validity, patient benefit, shelf life, process safety, reaction order and safe*. The gate includes negations and is incomplete for other wording and languages. These families apply to headlines and claim text regardless of kind/status. Use Ea in bounded claim prose because the activat* family is conservative. Association is never causality; computation is never physical or clinical validity; absence is unavailable, never negative evidence; review approval is never truth.

Human gates occur only before installation, restricted transfers, a new host, GPU/remote/heavy compute or an interpretation-changing choice. This pack performs none of those operations. A missing essential choice is a blocker; an unavailable numerical result is an explicit artifact state, not permission to invent evidence.
