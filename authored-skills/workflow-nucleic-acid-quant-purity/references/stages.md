# Nucleic-acid absorbance stages and local record contract

Every checked-in reading, question and expected artifact is a synthetic fixture. These procedures establish software arithmetic only, never observational validity, sample quality or independent review.

## Invocation and immutable identities

Public entry points are validate_nucleic_acid_quant_purity_pack(bundle) and compute_quant_purity(readings, rules, purity_bands=None) in codex_science.nucleic_acid_quant_purity_pack. The file validator takes one bundle JSON argument and writes nothing.

```bash
python3 scripts/validate_nucleic_acid_quant_purity_pack.py examples/workflow-nucleic-acid-quant-purity/pack.json
```

Acceptance prints JSON on stdout with exit 0. All refusals, including missing, extra or unknown arguments, print JSON with status refused and finding on stderr with exit 2. Help prints plain usage on stdout with exit 0. There is no output option. Concurrent calls independently read immutable inputs. Interruption leaves every input unchanged and can truncate stdout; the coordinator must capture durable output atomically. The validator writes no file, ref or record.

Each artifact identity is exactly path and sha256: a canonical relative POSIX path within the bundle and lowercase 64-hex SHA-256 of the parsed bytes. The entry-point pack has no initial declared hash. Refuse absolute artifact paths, traversal, backslashes, noncanonical spellings, symlink components, special files and unavailable inputs. Pin the root by walking every directory component from the filesystem root through directory descriptors with O_DIRECTORY, O_NOFOLLOW and O_NONBLOCK. Compare lstat/fstat device/inode at each open and retain every ancestor identity. Read artifacts relative to pinned directory descriptors with lstat regular-file check, O_NONBLOCK and O_NOFOLLOW, matching fstat signature, size check, bounded read and post-read signature check. Hash the bytes parsed. Cache bytes and parsed JSON by device/inode; hardlink aliases are initially read and parsed once. Re-read each distinct inode once at the end; compare every alias and the entire root ancestor chain before and after the final hash recheck. Growth, replacement and transient symlink swaps are labelled refusals. Preserve original failed bytes without automatic repair.

## Limits and types

Named module constants: MAX_BYTES 67108864 per file; MAX_TOTAL_BYTES 268435456 aggregate initial bytes across distinct inodes; MAX_NODES 4000000 JSON values per bundle; MAX_ROWS 10000 total replicate readings and generic JSON entries per container; MAX_SAMPLES 128; MAX_REPLICATES 128 per sample; MAX_RECORDS 128 claims, citations per claim, evidence artifact identities and aggregate evidence records; MAX_STRING 4096 characters; MAX_DEPTH 32; MAX_NUMBER 1e100 generic absolute numeric magnitude. Check dimensions before proportional sets, scans or recomputation. Byte-limit equality passes; excess refuses before reading. Before json.loads, bound root plus commas plus nonempty containers with a non-consuming iterator; quoted punctuation can conservatively overcount. Apply the remaining aggregate allowance before every new parse. Hardlinks consume budgets once.

All numbers are finite; bool is never a number. The only declared input integer, minimum_replicates, is a real int from 2 to MAX_REPLICATES. All summary counts are also real ints, never float, bool or numeric string. JSON refuses duplicate keys at every depth, NaN, Infinity, overflowing or huge floats/integers, non-object roots, excessive nesting and malformed UTF-8 with labelled findings. Identity strings are bounded, nonempty text. Every schema has exact fields; unknown and missing fields refuse.

Path length is finite in 1e-6 to 10 cm inclusive; dilution factor is finite in 1 to 1e12 inclusive. Absorbance readings are finite in -100 to 100 inclusive. Linear-range endpoints satisfy 0 <= minimum < maximum <= 100 with width greater than RELATIVE_ZERO times maximum. Purity-band endpoints satisfy 0 <= minimum <= maximum <= 100; agreement bound is finite in 0 to 1 inclusive. RELATIVE_ZERO is 1e-12. RELATIVE_TOLERANCE is 1e-8: compare every reported numeric value with relative tolerance only and zero absolute tolerance. EDGE_TOLERANCE is 1e-12: band revisions and conversion factors must match the frozen values at that tolerance, and inclusive range, band and replicate-difference decisions use it. Values near zero never get an absolute acceptance window.

## Pack-local schemas

All six schemas are ordinary domain artifacts, registered with separate existing claim-register entries; no global schemas change. Every input includes schema equal to its name and fixture equal to synthetic fixture.

- nuc-pack-v1: rules, readings and report artifact identities; evidence list of identities; frozen_rules_sha256 equal to rules.sha256; real boolean frozen_before_readings_read true. Check the freeze before reading table bytes are opened. This declares order without proving historical timing.
- nuc-rules-v1: samples, blank_id, wavelengths, path_length_cm, background_rule, blank_rule, linear_a260_range, purity_bands, minimum_replicates and replicate_max_relative_difference. samples is a nonempty bounded list of exactly sample_id, analyte, conversion_factor_ng_ul and dilution_factor. IDs are unique and exclude blank_id. Analyte is dsDNA or RNA; the conversion factor is respectively 50 or 40 ng/µL per 1 cm A260 unit. wavelengths is exactly ordered A230, A260, A280, A320. background_rule is subtract-A320. blank_rule is subtract-background-corrected-blank. linear_a260_range is exactly minimum and maximum applied to background-corrected and blank-subtracted A260 at the measured path length, before 1 cm scaling. purity_bands has exactly dsDNA and RNA, each with a260_a280 and a260_a230, each with minimum and maximum. The minimum number of technical replicates and relative agreement rule are frozen before readings.
- nuc-readings-v1: blank and samples. blank is exactly sample_id and reading, with the frozen blank ID and a measured reading. samples is a nonempty list of exactly sample_id and replicates, matching every frozen sample once. Every reading is exactly replicate_id, availability, A230, A260, A280 and A320. Replicate IDs are globally unique including the blank. availability is observed or unavailable; observed values are finite numbers, unavailable values are all null, never zero. Blank must be observed with nonnegative background-corrected wavelengths. All sample rows have at least minimum_replicates readings; missing samples require explicit unavailable rows, never omission or inferred negative evidence.
- nuc-report-v1: rules_sha256, exploratory, purity_bands, background_rule, blank_rule, samples, summary, headline and claims. exploratory is a real boolean. Changed purity bands require exploratory true and recomputation; the original frozen rules remain unchanged. Background, blank, analytes, factors, dilution, path, range and replicate rules remain frozen. Headline and claims pass the boundary gate before numerical computation. Reported samples, replicates, flags and summary must match the reference.
- nuc-evidence-v1: records list. Each record is exactly id, kind, result, origin and source. IDs are unique across all evidence documents. Kind/result are nonempty text. Source is a hash-bound artifact identity. Origin is internal, external, independent or preregistered. Non-internal source path AND hash must differ from the pack, rules, readings, report and every evidence-document identity; content copies and hardlinks cannot establish independence. Non-aliasing alone never proves actual independence.
- nuc-result-v1: validator-produced schema, fixture, status arithmetic-only, review unavailable, ordered stages, exploratory, inputs with path and sha256, computation, claims and limitations. It is unreviewed output, never a review receipt. expected.json wraps computation with the synthetic fixture label. negative-cases.json contains labelled synthetic fixture mutations with id, target, path, value, remove and finding; tests materialize independent bundles with fresh hashes.

Each computed sample is exactly sample_id, analyte, replicates, classification, concentration_ng_ul, a260_a280, a260_a230, replicate_relative_difference and flags. Classification is quantified or unavailable. Each replicate is exactly replicate_id, corrected, concentration_ng_ul, a260_a280, a260_a230 and flags. corrected is exactly A230, A260 and A280, or unavailable for a missing reading. flags is an ordered list of failed-control and ratio-excursion strings. Summary is exactly integer n, quantified, unavailable and flagged; flagged counts samples with any flag, including ratio excursions. No pooled concentration mean across analytes is reported. Every unavailable numeric quantity is the literal string unavailable.

## 01-rule-freeze

Input: coordinator question, assumptions, proposed claim IDs and planned sample identities. Call $cx-statistical-decision-analysis for decision and uncertainty framing and $science-provenance for immutable rules.json plus hash as nuc-rules-v1. Output: rule identity, existing manifest plan step and one checkpoint. Freeze factors, path, dilution, wavelength, blank, background, corrected-A260 range, analyte bands and replicate rules. Preserve rejected choices. Human decision only for an interpretation-changing choice or restricted action; no stage-specific approval for admitted local work.

## 02-reading-qc

Input: frozen rule identity and readings.json path-plus-hash as nuc-readings-v1. Call descriptor-pinned admission and identity checks. Output: admitted immutable inputs and retained QC information in nuc-report-v1. Refuse mixed blank/sample identities, duplicates, missing blank, wrong types, unknown analytes and missing sample rows. Missing replicate values remain explicit unavailable. Preserve all raw readings and failures. No file is repaired or dropped. No additional human gate for local read-only checks.

## 03-quant-purity

Input: immutable rules and readings plus effective report bands. Call compute_quant_purity and scripts/validate_nucleic_acid_quant_purity_pack.py. Output: full replicate and sample quantities in nuc-report-v1, independently recomputed into nuc-result-v1. First compute blank wavelength Bλ minus B320. For each sample replicate compute Cλ = (Aλ minus A320) minus (Bλ minus B320), for λ 230, 260 and 280. Concentration in ng/µL is C260 times the analyte factor times dilution divided by path_length_cm (relative to 1 cm). Ratios are C260/C280 and C260/C230. Path and dilution do not change ratios.

If any corrected absorbance is negative, A260 lies outside the inclusive frozen range, C260 is zero or relatively singular, or either denominator is non-positive or relatively singular, all that replicate's ratios AND concentration remain unavailable. Singularity threshold is RELATIVE_ZERO times the largest absolute raw sample or blank reading across all four wavelengths. Keep corrected values and flags negative-absorbance, outside-linear-range, non-positive-denominator and degenerate-signal; missing readings retain missing-reading. No division occurs for these invalid readings, and no zero substitutes for unavailable. The conservative cancellation threshold is a numerical bound, never a calibrated assay detection limit.

For valid replicates flag a260_a280-outside-band and a260_a230-outside-band when outside the inclusive effective analyte bands. These flags do not discard numeric values. If every replicate is numeric, agreement is (maximum concentration minus minimum concentration) divided by maximum concentration. Equality to the frozen bound passes; excess refuses as replicate-disagreement. The sample values are arithmetic means of replicate concentrations and ratios using math.fsum. One unavailable replicate prevents all sample-level pooling; sample quantities and agreement remain unavailable. Technical replicates never count as independent samples. Stop for a failed replicate-control rule; preserve its readings. No human gate unless changing interpretation.

## 04-summary

Input: full computed sample records and original identities. Call the reference summary checks. Output: nuc-report-v1 summary with sample n, quantified, unavailable and flagged denominators. Preserve failed controls, ratio excursions, negative results, missingness, uncertainty, sensitivity needs and exclusions. No hypothesis tests or empirical uncertainty intervals are invented. A ratio excursion cannot identify a contaminant or a downstream outcome. No additional gate.

## 05-handoff and claim gate

Input: report/evidence identities, full rules, readings, failures and coordinator records. Call $science-provenance to register ordinary artifacts and separate claim-register entries and $science-review in record, source and method modes. Output: nuc-result-v1 plus the coordinator's checkpoint, claim register and eventual independent receipt. The pack always leaves review unavailable. Preserve every failed control and negative result in original bytes and caller-captured refusal JSON.

Claims are exactly id, kind, status, text and evidence IDs. Kind is descriptive or associational. Status is planned, supported, replicated, suggestive, conflicting, unsupported, withdrawn or unavailable. Empty evidence requires unavailable. Any citation with kind OR result unavailable requires unavailable for every other status, including mixed observed evidence. An unavailable claim cannot assert supported, replicated, suggestive or significant evidence. Replicated is always refused because one synthetic fixture cannot establish two independent studies. Positive statuses supported, replicated and suggestive refuse any citation whose kind OR result denotes review, approval, computation, numerical agreement, truth, physical or clinical validity. Labels cannot replace evidence.

The conservative case-insensitive English whole-word/prefix wording families are: caus*, mechanis*, therap*, clinic*, efficac*, effective*, treat*, cure*, prevent*, recommend*, prescri*, bind*, affinit*, inhibit*, activat*, regulat*, drive/drives/driv*, induc*. Also refuse truth, physical validity, patient benefit, quality, suitab*, sequenc*, clon*, PCR, downstream and safe*. This applies to headlines and all claim statuses, includes negations and is incomplete for unlisted paraphrases and other languages. Association is never causality; numerical agreement is never physical or clinical validity; absence of a record is unavailable, never negative evidence; review approval is never truth. Sample quality and suitability for sequencing, cloning, PCR or any downstream use are outside this pack.

Human gates apply only before installation, restricted transfers, new hosts, GPU/remote/heavy compute or interpretation-changing choices. This pack performs none of those operations. The coordinator owns independent review and rigor classification; reviewer approval cannot turn a claim into truth.
