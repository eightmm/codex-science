# GWAS summary QC stage contracts

All example inputs and outputs are synthetic fixtures, never biomedical findings.

## Invocation and immutable identities

`python3 scripts/validate_gwas_summary_qc_pack.py examples/workflow-gwas-summary-qc/pack.json`

One positional bundle JSON argument; stdout is JSON, success exit 0, labelled refusal exit 2. There is no output option and the validator writes nothing. `reference_computation(table, protocol, *, p_threshold=None, window_bp=None)` is the small stdlib-only in-memory reference; `validate_gwas_summary_qc_pack(bundle)` is the public hash-bound entry point. In-memory overrides are computation parameters; the bundle validator separately enforces exploratory labelling.

Read every initial artifact exactly once, hash those bytes, parse each distinct inode once, then re-read distinct inodes for the final hash check. Open the absolute bundle parent component by component through pinned directory descriptors with O_DIRECTORY|O_NOFOLLOW; compare lstat/fstat device/inode and final ancestor identity chains. Read relative to the pinned root with O_NONBLOCK|O_NOFOLLOW, regular-file and size checks, a bounded size+1 read and descriptor identity checks. Refuse symlinks, FIFOs, devices, directories, hardlink mutation, replacement and growth. Hardlink aliases share reads, parsing and budgets. Artifacts must use canonical relative POSIX paths without absolute paths, dot/dotdot components, backslashes or symlinked components. Every handoff has exactly path and lowercase 64-hex sha256 fields. No files, refs or records are written by this validator: a second concurrent call is independent; termination between reads leaves input artifacts intact and possibly incomplete stdout only.

## Bounds and record validation

Named module constants: MAX_BYTES=64 MiB per artifact, MAX_TOTAL_BYTES=256 MiB across distinct inodes, MAX_ARTIFACTS=128 named artifacts, MAX_JSON_VALUES=4,000,000 per bundle, MAX_ROWS=10,000 variants or signal/list entries, MAX_RECORDS=128 claims/evidence records/reasons, MAX_ITEMS=20,000 entries per generic JSON container, MAX_STRING=4096 characters, MAX_DEPTH=32, MAX_NUMBER=1e100 absolute numeric magnitude. Before json.loads enforce a conservative value upper bound: 1 + commas + non-empty containers (including commas in strings, so some large strings may be refused conservatively). Charge it once per parsed inode. Check list counts before sets, sorting or per-row computations; enforce aggregate bytes from fstat before reads. Strings are nonempty and contain no surrogate code points. JSON refuses nested duplicate keys, non-object roots, NaN/Infinity, huge numbers and excessive nesting with labelled ValueError messages.

Every declared integer is a real int: schema_version=1, minimum_n in [2, 10^9], window_bp in [0, 10^9], row n in [0, 10^9] and positions in [1, 10^9]. Bool, integral floats and numeric strings are refused. p_threshold is in (0,1], inflation_limit in [1,100], minimum_frequency in [0,0.5] and p_relative_tolerance in [0,0.1]. All booleans are real bools. No record format existed before this new pack; no older stored record class changes validation.

## Pack-local schemas

All records have a schema string and fixture="synthetic fixture". Exact allowed keys (unknown/missing keys refused):

- `gwas-summary-qc-pack-v1` (pack.json): `evidence`, `fixture`, `frozen_before_table_read`, `frozen_protocol_sha256`, `protocol`, `report`, `schema`, `stages`, `table`.
- `gwas-summary-qc-protocol-v1` (protocol.json): `ancestry`, `effect_allele_convention`, `fixture`, `genome_build`, `inflation_limit`, `minimum_frequency`, `minimum_n`, `p_relative_tolerance`, `p_threshold`, `schema`, `schema_version`, `trait`, `window_bp`.
- `gwas-summary-qc-table-v1` (table.json): `fixture`, `genome_build`, `rows`, `schema`, `schema_version`.
- `gwas-summary-qc-report-v1` (report.json): `ambiguous`, `claims`, `excluded`, `exploratory`, `fixture`, `frequency_checked`, `headline`, `inflated`, `lambda_gc`, `p_threshold`, `protocol_sha256`, `schema`, `signals`, `validated`, `window_bp`.
- `gwas-summary-qc-evidence-v1` (evidence.json): `fixture`, `records`, `schema`.
- `gwas-summary-qc-result-v1` (expected.json): `claims`, `computation`, `exploratory`, `fixture`, `inputs`, `limitations`, `review`, `schema`, `stages`, `status`.

Table rows have exactly id, chromosome (nonempty label), position (bp), effect_allele, other_allele, original_effect_allele, original_other_allele (distinct uppercase A/C/G/T pair), flip_declared (bool), beta, se, p, n and frequency (effect allele frequency). Already-harmonized beta/frequency refer to current effect_allele; a declared flip requires current alleles to be the exact original reversal. The validator checks declarations, never applies flips or proves original extraction. Evidence records have exactly id, kind, result, origin and source; origin is internal, external, independent or preregistered; source is path-plus-hash. Claims have exactly id, kind (descriptive/associational), status, text and evidence (unique IDs). Existing claim status vocabulary is retained, with replicated refused here. Signal entries have id, chromosome, position, p, label="positional signal" and inflated_risk (bool). Exclusions have id and nonempty unique reasons. Result computation mirrors the report's lambda_gc, inflated, signals, excluded, ambiguous, frequency_checked and validated fields. Results add no keys to existing global records.

## 01-freeze: rules before outcomes

Input: protocol.json path+hash and matching frozen_protocol_sha256, with frozen_before_table_read=true. The exact rule fields are those above, including build, trait, ancestry, allele convention, threshold, inflation limit, minimum n, window, minimum frequency and relative tolerance. Calls: `$cx-statistical-decision-analysis` for framing, existing `$science-provenance` for identities; local validator for checks. Output: gwas-summary-qc-protocol-v1 and the ordinary frozen artifact identity. The validator admits protocol and freeze before opening table.json. It cannot retrospectively prove time order outside its own execution. Missing freeze stops with protocol-freeze; a post-outcome threshold/window change without exploratory=true stops with post-hoc-change. A labelled change retains the frozen protocol and recomputes with the report override. Human decision only for an interpretation-changing choice.

## 02-harmonization: identities and alleles

Input: table.json path+hash, after the protocol is admitted. Calls: local validator, with `$cx-biomedical-entity-normalization` only if a separately authorized source-normalization step is needed. Output: gwas-summary-qc-table-v1. Duplicate IDs stop with duplicate-variant; build mismatch with genome-build; mismatched original/current orientation with undeclared-flip. A/T and C/G produce ambiguous-strand exclusions. Frequency range and minimum-frequency checks apply only to nonambiguous strands. They are never frequency_checked, validated or signals; misuse stops with ambiguous-frequency. Do not rewrite input or resolve strand using frequencies. raw-table.json is an intentionally duplicated synthetic input; table.json is an explicitly prepared distinct synthetic fixture, not a silent validator repair. No new human gate for offline admission.

## 03-consistency: retained failures

Input: same immutable table and frozen protocol hashes. Calls: reference_computation using math.erfc. Output: excluded/ambiguous/frequency_checked/validated lists in gwas-summary-qc-report-v1. Compute z=beta/se and expected p=erfc(abs(z)/sqrt(2)); mismatch when abs(p-expected) > frozen tolerance * max(p,expected). p must be in (0,1]; zero p stops with p-zero, tail underflow with p-underflow. Invalid finite ranges, se<=0, n below minimum, minor-allele frequency below minimum or p disagreement are excluded and reasons retained. Non-finite or excessive z stops with numerical-range. An inconsistent row claimed validated stops with p-inconsistent, a low-n row claimed as a signal with sample-size-signal. At least two accepted variants and nonzero chi-square variance are required (degenerate-input). No retry without corrected input and preserved prior failure. No new human gate.

## 04-signals: bounded positional summary

Input: unchanged table/protocol identities and report.json path+hash. Calls: stdlib median and local reference. Output: gwas-summary-qc-report-v1, checked against gwas-summary-qc-result-v1. lambda_GC=median(z squared)/0.4549 over validated rows; p<=threshold qualifies, inflation is lambda>limit (equality passes). Sort qualifying rows by (p,id); greedily retain a lead only if on a different chromosome or farther than window bp from every retained lead (window equality excludes). No LD independence is inferred. Every positional signal and the report must flag inflation risk above the limit or inflation-flag refuses it. Null signals and failed controls remain visible. No human gate for the small CPU fixture.

## 05-handoff: claims and review boundary

Input: all prior path+hash identities and each evidence.json path+hash plus its hashed sources. Calls: `$science-provenance` and coordinator-owned `$science-review` in record/source/method modes. Output: ordinary domain artifacts and separate existing claim-register entries; local result remains statistical-association-evidence-only, review unavailable. One coordinator checkpoint tracks the five ordered IDs, using the plan's existing id/description/status shape. No global schema or execution engine is added.

Every claim is wording-checked regardless of kind/status. Conservative English lexical families, case-insensitive whole words with prefix families implemented using \w*: caus*, mechanis*, therap*, clinic*, efficac*, effective*, treat*, cure*, prevent*, recommend*, prescri*, bind*, affinit*, inhibit*, activat*, regulat*, drive/drives/driv*, induc*. Additional refusals cover truth, physical validity and patient benefit. This lexical gate is incomplete for unlisted paraphrases and includes negations. Keep these exact families in code, stages and quality. Positive statuses supported/replicated/suggestive cannot cite computed or review-approval evidence: inspect both kind and result (non-evidence-support). Any unavailable kind/result in any citation requires unavailable status (unavailable-evidence), even mixed with observed evidence. Empty evidence requires unavailable; unavailable text cannot say supported, replicated, suggestive or significant (unavailable-positive). Replicated is refused (claim-replication). Sources declared external, independent or preregistered must have a path and hash distinct from every study-owned input/output artifact (external-alias); labels cannot prove real independence. Missing sources stop as unavailable input, never negative evidence. Failed controls and negative results must survive coordinator packaging. Review approval is never truth; numerical agreement is never physical or clinical validity. Only new hosts, restricted transfers, installation, GPU/remote/heavy compute or interpretation-changing choices require human gates; none are performed here.
