# HPLC stages and local record contract

All checked-in peak tables, questions, negative cases and expected artifacts are synthetic fixtures. This reference establishes software arithmetic acceptance only. It does not establish observational validity or review approval.

## Invocation and immutable identities

Public entry points are validate_hplc_system_suitability_pack(bundle), compute_suitability(table, rules, applied_limits=None) and sample_rsd(values, minimum), in codex_science.hplc_system_suitability_pack.

```bash
python3 scripts/validate_hplc_system_suitability_pack.py examples/workflow-hplc-system-suitability/pack.json
```

The CLI takes one bundle argument, writes nothing, and prints accepted JSON on stdout with exit 0. Every refusal, including missing, extra and unknown arguments, is JSON on stderr with status refused and finding, exit 2. Help is plain usage on stdout, exit 0. There is no output option. Concurrent calls read immutable inputs independently; a kill leaves supplied files unchanged and may truncate stdout. A caller persisting results must capture them atomically. No file, ref or record is written by the validator.

Each artifact identity is exactly path and sha256: a canonical relative POSIX path inside the bundle and lowercase 64-hex SHA-256 of the same bytes parsed. The entry pack has no initially declared hash. Refuse absolute artifact paths, traversal, backslashes, noncanonical paths, symlink components, special files, missing paths and escaped paths. Pin the bundle by walking every absolute component from the filesystem root with directory descriptors, O_DIRECTORY, O_NOFOLLOW and O_NONBLOCK. Compare each lstat/fstat device/inode, retain the final descriptor, and record every ancestor identity. Open artifacts relative to pinned directory descriptors, compare lstat and fstat signatures, require regular files, bound the read and check the post-read signature. Cache bytes and parsed JSON by device/inode so hardlink aliases consume the initial read and parse budgets once. Re-read each distinct inode once at final validation, recheck every alias and compare the entire ancestor chain before and after. Refusals never repair or overwrite inputs.

## Limits and types

Module constants: MAX_BYTES 67108864 per regular artifact; MAX_TOTAL_BYTES 268435456 aggregate initial bytes across distinct inodes; MAX_NODES 4000000 JSON values per bundle; MAX_ROWS 10000 injection rows, standard IDs, blank IDs, RSD values and generic JSON entries per container; MAX_PEAKS 128 peaks per injection; MAX_RECORDS 128 claims, evidence artifact identities, total evidence records and citations per claim; MAX_STRING 4096 characters; MAX_DEPTH 32; MAX_NUMBER 1e100 generic absolute numeric magnitude. Bounds are checked before proportional sets, scans, allocation, parsing or arithmetic. Equality with byte/count bounds passes. Preparse JSON allowance conservatively counts the root, commas and nonempty containers with an iterator rather than allocating a match list; punctuation inside strings can overcount. Remaining allowance is enforced before each new parse.

Measured positive quantities are finite in 1e-12 to 1e12 inclusive. Standard peak areas must be positive; blank areas and recorded signal-to-noise allow zero. Acceptance limits are finite in 0 to 1e12 inclusive. Front distance must be less than the five-percent width, and half-height width cannot exceed that width. Every declared integer (injection_count, minimum_injections, order and report replicate_count) is a real int, never bool, float or string. Planned and minimum counts satisfy 2 <= minimum_injections <= injection_count <= MAX_ROWS. Order satisfies 1 <= order <= MAX_ROWS and increases strictly. JSON refuses nested duplicate keys, NaN/Infinity, huge numbers, malformed UTF-8/JSON, non-object roots, excessive nesting and oversized strings with labelled ValueError findings. No missing measurement is imputed.

## Pack-local schemas

All six schemas are ordinary domain artifacts, separate from existing receipts and claim-register sidecars. Every input has schema equal to its schema name and fixture equal to synthetic fixture. Object fields are exact; unknown or missing fields refuse.

- hplc-pack-v1: rules, table and report artifact identities; evidence list of artifact identities; frozen_rules_sha256 equal to rules.sha256; real boolean frozen_before_table_read true. Freeze is checked before opening table bytes. The declaration cannot establish historical timing.
- hplc-rules-v1: analyte_peak_id; reference_peak_id (different nonempty identity or null); unique nonempty disjoint standard_ids and blank_ids; integer injection_count equal to standard_ids length; integer minimum_injections; limits; rsd_method sample-stdev; plates_width half-height; numeric plates_constant 5.54; numeric tailing_height 0.05; resolution_width baseline; blank_rule preceding-standard; time_unit minute; area_unit arbitrary. Limits are exactly retention_time_rsd_max, peak_area_rsd_max, tailing_max, plates_min, resolution_min, signal_to_noise_min and carryover_max. Planned injection_count counts standards, not blanks.
- hplc-table-v1: nonempty rows. Each row is exactly injection_id, integer order, kind (standard or blank), peaks. A row identity must match its frozen kind. Missing standards are allowed and reduce actual replicate count; every frozen blank must be present. Each peak is exactly peak_id, retention_time, area, width_half_height, width_five_percent, front_five_percent, width_baseline, signal_to_noise. Peak IDs are unique per injection. The analyte and optional reference must exist in every standard. Missing nearest peaks and null signal_to_noise yield unavailable criteria. A blank missing its analyte peak yields unavailable carryover, never zero. A recorded blank peak with area zero yields zero carryover. Every blank must immediately follow a recorded standard; two consecutive blanks refuse.
- hplc-report-v1: rules_sha256; real boolean exploratory; applied_limits with the seven limit fields; rsd_method, plates_width, plates_constant, tailing_height and resolution_width matching frozen rules; headline; claims; replicate_count; replicate_ids; injections; replicate_criteria; carryover; summary. Changed applied limits require exploratory true and recomputation while retaining original rules. No formula or width change is allowed. Wording and evidence gates run before table arithmetic so boundary refusals are not masked by later numerical failures.
- hplc-evidence-v1: records list; each record is exactly id, kind, result, origin and source. IDs are unique across evidence documents. Kind/result are bounded text; origin is internal, external, independent or preregistered; source is a hash-bound artifact identity. Every non-internal source path and hash must differ from the pack, rules, table, report and evidence-document identities, including content/hardlink aliases. This only checks non-aliasing, not real-world independence.
- hplc-result-v1: validator-produced schema, fixture, status arithmetic-only, review unavailable, ordered stages, exploratory, inputs path/hash identities, computation, claims and limitations. It is never an independent review receipt. Expected.json wraps computation with a synthetic fixture label. Negative-cases.json contains labelled mutations with target, path, value, remove and finding; tests materialize fresh hashed bundles for each.

Computation contains integer replicate_count, ordered replicate_ids, injections, replicate_criteria, carryover and summary. Each injections item is injection_id, nearest_peak_id (or unavailable), plates, tailing, resolution and signal_to_noise. Each criterion is exactly value (number or unavailable) and status (pass, fail, unavailable). Replicate_criteria has retention_time_rsd and peak_area_rsd. Each carryover item has injection_id, preceding_standard_id, value and status. Summary has all seven criterion names: retention_time_rsd, peak_area_rsd, plates, tailing, resolution, signal_to_noise, carryover. Reported numbers match the reference with relative tolerance 1e-9 and zero absolute tolerance, including near-zero values. Count fields remain exact integer types. The result has no overall suitability or release approval.

## 01-rule-freeze

Input: coordinator question, assumptions, descriptive claims and intended identities. Call decision framing in $cx-statistical-decision-analysis and $science-provenance. Output: rules.json path/hash as hplc-rules-v1, an existing manifest plan step and one coordinator checkpoint. Freeze identities, counts, all limits, heights, widths, formulas, units and blank rule before table admission. Stop for essential missing choices. Interpretation-changing revisions need a human decision and exploratory labelling; no per-stage prompt is needed.

## 02-table-qc

Input: immutable rules.json and table.json identities. Call validator identity and table checks. Output: admitted hplc-table-v1 ordinary artifact with original failures preserved. Check IDs, order, finite positive retention times and widths, recorded heights and standard/blank separation. Missing standards reduce actual count. Missing required blank or standard analyte/reference refuses; absent neighbor, blank peak or signal record yields unavailable. Width-height measurements and peak assignment are supplied assumptions, not validated observations. Never omit failed controls.

## 03-suitability

Input: admitted rules/table path-plus-hash identities and applied limits. Call compute_suitability through the one-argument CLI. Output: values/statuses in hplc-report-v1 and hplc-result-v1. RSD percent = 100 times statistics.stdev(values) divided by math.fsum(values)/n, with sample denominator n-1. If n is below minimum_injections, return unavailable, never zero or pass. If admitted replicates have zero variance, refuse degenerate-rsd. No significance test or interval is produced.

Per standard injection, N = 5.54 times (retention_time/width_half_height)^2. T = width_five_percent/(2 times front_five_percent), both measured at 0.05 peak height. Select the other peak with smallest absolute retention-time distance; exact-distance ties use first table order. Rs = 2 times absolute retention-time difference divided by the sum of the two baseline widths. Equal retention times yield zero resolution and can fail the frozen limit. A farther reference peak cannot replace a nearer neighbor. Signal-to-noise is the supplied ratio, not a computed or validated detector measurement. Carryover percent = 100 times blank analyte area divided by the immediately preceding standard analyte area; missing blank peak remains unavailable. Reference identity is checked when frozen but does not normalize analyte area.

Upper limits pass at <= for retention-time RSD, area RSD, tailing and carryover. Lower limits pass at >= for plates, resolution and signal-to-noise. Equality passes, including zero where a quantity permits it. Failing controls produce fail statuses retained in the report; malformed or contradictory records refuse.

## 04-summary

Input: all computed injection and replicate criteria with original identities. Call exact shape and reference result checks. Output: actual standard count/IDs and all seven summary criteria in hplc-report-v1. Within each criterion, fail takes precedence, then unavailable, then pass. No observations for a criterion yield unavailable. A report omitting or hiding any failed criterion refuses. Preserve negative results, conflicts, assumptions, sensitivity needs and excluded identities; do not inflate actual n or insert blanks into replicates.

## 05-handoff and claim gate

Input: report/evidence identities, original rules/table, failed controls and coordinator records. Call $science-provenance to register ordinary artifacts and separate claim-register entries. Call $science-review for independent record, source and method review. Output: hplc-result-v1 plus the coordinator's existing checkpoint/claim register and later independent receipt. This pack never marks itself reviewed or equates approval with truth.

Claims are exactly id, kind, status, text, evidence IDs. Kind is descriptive or associational. Status is planned, supported, replicated, suggestive, conflicting, unsupported, withdrawn or unavailable. Empty evidence requires unavailable. Citing any unavailable kind or result requires unavailable for every other status, including mixed observed/unavailable citations. Unavailable text cannot assert supported, replicated, suggestive or significant evidence. Replicated always refuses because one synthetic fixture cannot establish two independent studies. Every positive status (supported, replicated, suggestive) refuses when any citation's declared kind or result denotes review, approval, computation, numerical agreement, truth, physical or clinical validity.

Conservative case-insensitive English whole-word/prefix wording families: caus*, mechanis*, therap*, clinic*, efficac*, effective*, treat*, cure*, prevent*, recommend*, prescri*, bind*, affinit*, inhibit*, activat*, regulat*, drive/drives/driv*, induc*. Also refuse truth, physical validity, patient benefit, method valid* (including method is valid*), product quality, system qualif* and release. The check includes negations and is incomplete for other languages or unlisted paraphrases. Claim kind never bypasses wording. Association is never causality; computation is never physical or clinical validity; absence of evidence is unavailable, never negative evidence; review approval is never truth.

Human gates apply only before installation, restricted transfer, a new host, GPU/remote/heavy compute or an interpretation-changing choice. This reference requires none of the external actions. Stop on essential absent input and retain all failed revisions; do not add a permission gate at every stage.
