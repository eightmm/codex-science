# Western blot stages and local record contract

All supplied intensities, dilution points, questions and expected artifacts are synthetic fixtures. This reference controls software arithmetic only. It is neither observational evidence nor independent review.

## Invocation and immutable identities

Public entry points in codex_science.western_blot_densitometry_pack are validate_western_blot_densitometry_pack(bundle), compute_densitometry(table, rules) and welch_fold_interval(first, reference, level=.95, minimum=3).

```bash
python3 scripts/validate_western_blot_densitometry_pack.py examples/workflow-western-blot-densitometry/pack.json
```

The CLI accepts one bundle, prints JSON on stdout and exits 0 on acceptance. Every refusal, including missing, extra and unknown arguments, prints JSON with status refused and finding on stderr, exit 2. Help is plain usage on stdout, exit 0. No output option exists. The validator writes nothing. A second concurrent call reads independently. A kill between reads leaves every supplied file unchanged and may truncate stdout; the coordinator captures durable output atomically. No file, ref or stored record is written by any public entry point.

An artifact identity is exactly path and sha256: canonical relative POSIX path within the bundle and lowercase 64-hex SHA-256 of parsed bytes. Absolute paths, traversal, backslashes, noncanonical spellings, symlink components and special files are refused. Pin every root ancestor from the filesystem root using directory-relative O_DIRECTORY, O_NOFOLLOW and O_NONBLOCK opens. Record every ancestor device/inode, compare lstat/fstat identities and retain the root descriptor. Read each artifact relative to pinned descriptors with lstat regular-file checks, O_NONBLOCK and O_NOFOLLOW, fstat identity and size checks, a bounded read and post-read signature check. Hash exactly the bytes parsed. Cache initial bytes and parsing by device/inode so hardlink aliases count once. Recheck every alias identity, reread each distinct inode once, rehash and compare the entire root ancestor chain at the end. Refuse input replacement or growth. Preserve failed bytes without automatic repair.

## Limits and types

Named module limits: MAX_BYTES 67108864 per regular file; MAX_TOTAL_BYTES 268435456 aggregate initial bytes across distinct inodes; MAX_NODES 4000000 JSON values per bundle; MAX_ROWS 10000 lanes and generic JSON entries per container; MAX_UNITS 128 distinct biological units and values per interval group; MAX_GROUPS 16; MAX_BLOTS 128; MAX_ANTIBODIES 16; MAX_DILUTIONS 64 points per antibody; MAX_RECORDS 128 claims, evidence documents, total evidence records and citations per claim; MAX_STRING 4096 characters; MAX_DEPTH 32; MAX_NUMBER 1e100 absolute generic magnitude; MAX_INTENSITY 1e12. Counts are bounded before proportional scans or allocation. Aggregate bytes are checked from fstat before reading a new inode. Preparse JSON allowance counts root, commas and nonempty containers using an iterator without a match list; quoted punctuation may conservatively overcount. Remaining allowance applies before each new parse.

MAX_ITERATIONS 256 bounds the beta continued fraction; QUANTILE_STEPS 96 bounds t-quantile bisection in the fixed 0 to 1e6 bracket. Nonconvergence refuses as welch-convergence. No normal fallback. Raw intensity and background are 0 to MAX_INTENSITY inclusive. Dilution amount and linear minimum are 1e-12 to MAX_INTENSITY; linear maximum is greater than minimum and strictly below saturation ceiling, which is at most MAX_INTENSITY. Maximum loading-control CV is 0 to 1 inclusive. Minimum biological n is a real integer from 3 to MAX_UNITS. Interval level is .5 to .999 inclusive. Public Welch biological values are finite in 1e-24 to 1e24 inclusive. Fold log bounds outside -700 to 700 refuse as degenerate-interval.

Every declared integer, including reported n and n_lanes, must be a real int, never bool, float or numeric string. All numbers are finite. Duplicate JSON keys at every nesting level, NaN/Infinity, huge numbers, non-object roots, deep nesting, malformed UTF-8 and wrong types are labelled refusals. Strings and keys are bounded nonempty text. No silent imputation.

## Pack-local schemas

These six schemas are ordinary domain artifacts. Each input has schema equal to its named schema and fixture equal to synthetic fixture. Fields are exact: unknown and missing fields refuse. No existing global schema or receipt changes.

- wb-pack-v1: rules, table and report artifact identities; evidence list of identities; frozen_rules_sha256 equal to rules.sha256; real boolean frozen_before_intensities_read true. Rule identity is checked before intensity bytes are opened. Declared ordering is not independent historical proof.
- wb-rules-v1: groups (at least two unique strings), reference_group belonging to groups, lanes, antibodies, reference_lanes, background_rule local-per-lane, normalisation target-over-loading-control, replicate_rule collapse-technical-before-biological, integer minimum_biological_units, maximum_loading_control_cv, interval_method welch-log-delta and interval_level. Each lane is exactly lane_id, sample_id, blot_id, biological_unit, group, target_band, loading_control_band. Lane IDs are unique; group must be frozen; a biological unit cannot span groups; a sample ID cannot map to multiple biological units. Target and loading control are distinct frozen antibody IDs. reference_lanes maps every blot ID to an existing lane from that blot. Each antibody is exactly antibody_id, minimum, maximum, saturation_ceiling and dilution_series. Each series point is exactly amount and intensity. At least three points have strictly increasing amounts, positive intensities spanning the exact frozen bounds, and proportional intensity/amount within relative tolerance 1e-9 and no absolute tolerance. These synthetic points do not validate an actual antibody range.
- wb-table-v1: nonempty rows, each exactly lane_id, target_intensity, target_background, loading_control_intensity, loading_control_background. Every frozen lane appears exactly once. The other four fields are either finite nonnegative numbers or all null for explicit unavailable. A partial null is refused. Corrected values are raw minus local background. Negative corrected values, raw values at or above saturation and corrected values outside inclusive linear ranges make a lane unreliable. Both ratios stay unavailable and the lane is excluded. Zero corrected values are outside the strictly positive frozen ranges; no division or log is attempted.
- wb-report-v1: rules_sha256 retaining original frozen identity; real boolean exploratory; complete applied_rules in wb-rules-v1 shape; computation; headline; claims. Applied rules differing from the original require exploratory true and full recomputation. Original rules are never overwritten. Headline and claims are gated before intensity arithmetic. Changed rule identities remain visible in the report hash and controlling references.
- wb-evidence-v1: records, each exactly id, kind, result, origin, source. IDs are unique across all evidence documents. Kind/result are nonempty text. Origin is internal, external, independent or preregistered. Source is a path-plus-hash identity. Every non-internal source path and hash must differ from every pack, rules, table, report and evidence-document identity. Hardlinks and content copies cannot establish independence. Non-aliasing alone cannot prove real-world independence.
- wb-result-v1: validator-produced schema, fixture, status arithmetic-only, review unavailable, ordered stages, exploratory, inputs (path and sha256), computation, claims and limitations. It is never a passed review receipt. expected.json wraps computation and the synthetic fixture label. negative-cases.json contains synthetic mutations with target document, path, replacement/removal and expected finding; tests materialize fresh hash-bound bundles.

Computation is exactly lanes, biological_units, groups and loading_control_cv. Each lane is lane_id, classification reliable or unreliable, reasons, ratio and scaled_ratio. Reasons retain negative-after-background, saturated-band, target-range, loading-control-range or unavailable. Each biological-unit record is biological_unit, group, integer n_lanes counting reliable technical lanes and mean or unavailable. Each group is group, integer n counting reliable biological units, mean, standard_error, fold_change and interval. Unavailable is a literal string, never zero. Intervals are either unavailable or exactly method welch-log-delta, level, degrees_of_freedom, lower and upper. Reference-group interval is unavailable because it is the comparison baseline. All reported fields are compared to reference values, with numeric relative tolerance 1e-9 and no absolute tolerance, including near-zero values.

## 01-rule-freeze

Input: coordinator question, assumptions, lane/sample/blot/biological-unit identities and intended claims. Call $cx-statistical-decision-analysis for decision framing and $science-provenance to register rules.json plus its hash as wb-rules-v1 before intensities. Output: immutable rules identity, existing manifest plan step and one coordinator checkpoint. Fix background, antibody ranges/dilution points/saturation, ratio rule, per-blot references, replicate collapse, loading-control CV, reference group, biological minimum and interval method/level. Preserve rejected alternatives. Stop for essential missing choices; an interpretation-changing revision needs a human decision and exploratory label. No routine stage permission prompt.

## 02-table-qc

Input: rules path/hash and table.json path/hash. Call the pack validator. Output: wb-table-v1 ordinary artifact and preserved lane QC in wb-report-v1. Validate identities before joining. Flag unreliable lanes before any log or division. An absent lane requires an explicit unavailable row. If a report includes an unreliable lane, refuse its first QC reason before aggregate controls can mask it. The reference lane on every blot must exist and be reliable; otherwise reference-lane refuses. Failed controls and negative results remain in original inputs and caller-captured refusal JSON.

## 03-normalisation

Input: admitted immutable table/rules and complete applied rules. Call compute_densitometry, welch_fold_interval and the one-bundle CLI. Output: lane, biological-unit and group records inside wb-report-v1 and wb-result-v1. Every lane on a blot must use its reference lane's antibody pair; mismatches refuse band-identity. For each reliable lane compute corrected target / corrected loading control, then divide by its blot's reference lane ratio. Collapse scaled technical lane values within each biological unit using their arithmetic mean. Repeats across blots still count as one biological unit. Calibration lanes are ordinary declared units in this small fixture; their dependence and calibration uncertainty remain limitations.

Loading-control CV is sample standard deviation / mean across all available nonnegative corrected loading controls, including target-unreliable lanes. Negative corrected controls are retained as QC failures and omitted from this CV. A zero mean refuses; fewer than two controls yields unavailable. CV above the frozen bound refuses loading-control-cv; equality passes. Saturated or out-of-range controls never enter ratios regardless of CV. Human review must assess any missing or failed controls.

For each group compute arithmetic mean and sample standard deviation / sqrt(n) over reliable biological units only; standard error is unavailable below two units. Fold change is group mean divided by reference-group mean, unavailable when either has no reliable units. For nonreference groups, if either n is below frozen minimum (at least three), interval is unavailable. Otherwise let a = sample variance / n / mean squared and b = reference variance / reference n / reference mean squared. Welch-Satterthwaite df = (a+b) squared divided by a squared/(n-1) + b squared/(reference n-1). The log-delta interval is exp(log(fold) plus or minus t(df, (1+level)/2) times sqrt(a+b)). This is an approximate interval for the ratio of arithmetic means, not an exact ratio interval. Zero variance or underflow refuses degenerate-variance. Beta continued fractions and bounded bisection invert Student t using the standard library. Use math.fsum for sums; no product-based sign comparisons. Reference-lane calibration uncertainty and cross-lane dependence are not propagated.

## 04-summary

Input: complete computed lane/unit/group records and original hashes. Call reference report checks. Output: denominators, group means, standard errors, fold quantities and unavailable intervals in wb-report-v1. Preserve exclusions, failed controls, null results, uncertainty, applicability, shared-reference dependence, sensitivity needs and rejected choices. Never count technical lanes as biological n or put unreliable lanes into means. No number establishes abundance changes, expression regulation, mechanism or clinical relevance.

## 05-handoff and claim gate

Input: report/evidence path-plus-hash identities, frozen rules, intensities, full QC, failures and coordinator records. Call $science-provenance for ordinary artifact registration and separate claim-register entries; $science-review for independent record, source and method review. Output: wb-result-v1 plus the coordinator's existing checkpoint, claim register and later independent receipt. The pack never marks itself reviewed. The coordinator owns rigor classification.

Claims are exactly id, kind, status, text and evidence IDs. Kind is descriptive or associational. Status is planned, supported, replicated, suggestive, conflicting, unsupported, withdrawn or unavailable. Empty evidence requires unavailable. Any unavailable kind or result requires unavailable status even when mixed with observed evidence and for every other status. Unavailable text cannot assert supported, replicated, suggestive or significant evidence. Replicated always refuses because one synthetic fixture cannot establish independent studies. Every positive status (supported, replicated, suggestive) refuses when any cited record's kind OR result denotes review, approval, computation, numerical agreement, truth, physical or clinical validity. Labels never replace evidence.

The conservative case-insensitive English whole-word/prefix wording families are: caus*, mechanis*, therap*, clinic*, efficac*, effective*, treat*, cure*, prevent*, recommend*, prescri*, bind*, affinit*, inhibit*, activat*, regulat*, drive/drives/driv*, induc*. Also truth, physical validity, patient benefit, protein abundan* and express*. The gate includes negations and is incomplete for unlisted paraphrases and other languages. Claim kind cannot bypass wording. Association is never causality; computed agreement is never physical or clinical validity; absence is unavailable, never negative evidence; review approval is never truth.

Human gates apply only before installation, restricted transfer, a new host, GPU/remote/heavy compute or an interpretation-changing choice. This pack performs none of those actions. Hash records alone cannot establish preregistration or independent support. Preserve failed controls and negative results for coordinator-owned review.
