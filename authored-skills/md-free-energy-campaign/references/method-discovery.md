# Current protocol discovery

Search current primary protocol documentation before selecting a route; the dated
[seeds](methods.json) are discovery aids, not installed environments or acceptance.
Record repository/release, protocol settings, engine and dependency identities,
force-field/parameter terms, supported chemistry/end states, required hardware,
data/redistribution rights and the official tutorial that matches the contrast.
Distinguish discovered, documented, preflight-ready and actually piloted methods.

OpenFE separates ChemicalSystem construction, protocol selection and ligand atom
mapping in its [setup guide](https://docs.openfree.energy/en/stable/guide/setup/index.html).
Use protocol-specific requirements for relative versus absolute calculations;
existing plain MD is not a relative free-energy estimator. Inspect connected
network results and uncertainty using the pinned analyzer; optional cinnabar
ranking is a different estimator from this pack's arithmetic diagnostic.

Additional methods may be admitted using an ordinary run-local descriptor with
source URL/access date, pinned code/environment identity, input/output and unit
contract, assumptions, controls, expected failures, resource envelope and pilot
evidence. Hash the descriptor and bind the chosen route before execution. No
global registry, implicit installation, permission or evidence upgrade follows
from a descriptor. If an engine is absent, preserve the preparation and exact
missing requirement; do not substitute toy values and call them simulation.
