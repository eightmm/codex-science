# CFU plate-count stages and local record contract

Every checked-in count, question and expected artifact is a synthetic fixture. This reference specifies arithmetic and software acceptance only. It is not observational evidence or independent review.

## Invocation and immutable identities

Public entry points: `validate_cfu_plate_count_pack(bundle)`, `compute_cfu(counts, rules, countable_ranges=None)` and `poisson_interval(count, exposure, level=0.95)` in `codex_science.cfu_plate_count_pack`. The file validator accepts one JSON bundle argument and writes nothing.

```bash
python3 scripts/validate_cfu_plate_count_pack.py examples/workflow-cfu-plate-counts/pack.json
```

The CLI prints JSON on stdout and exits 0 on acceptance. Every refusal, including missing, extra or unknown arguments, prints JSON with status refused and finding on stderr and exits 2. Help is plain usage on stdout with exit 0. There is no output option. A concurrent call reads the same immutable inputs independently. Interruption leaves all supplied files unchanged and may truncate stdout; the coordinator must capture durable output atomically. Nothing in this validator writes a file, ref or record.

Each artifact identity is exactly an object with path and sha256: a canonical relative POSIX path within the bundle plus a lowercase 64-hex SHA-256 of the bytes parsed. The entry-point pack has no initial declared hash. Absolute artifact paths, traversal, backslashes, symlink components, noncanonical spellings, special files and unavailable paths are refused. The root is walked from the filesystem root through directory descriptors using O_DIRECTORY, O_NOFOLLOW and O_NONBLOCK. Record every ancestor device/inode, compare lstat with fstat during opening, retain the root descriptor and compare the entire chain at final rechecks. Artifacts are opened relative to pinned directories with lstat regular-file validation, O_NONBLOCK and O_NOFOLLOW, descriptor fstat, a bounded read and post-read signature check. Hash the same bytes that are parsed. Cache bytes and parsed JSON by device/inode so hardlink aliases are initially read and parsed once. Re-read each distinct inode once at the end to refuse replacement or growth, and recheck every alias identity and the whole ancestor chain. Refusals preserve failed input bytes; there is no automatic repair.

## Limits and types

Named module limits: MAX_BYTES 67108864 per regular file; MAX_TOTAL_BYTES 268435456 aggregate initial raw bytes across distinct inodes; MAX_NODES 4000000 JSON values per bundle; MAX_ROWS 10000 plates and generic JSON entries per container; MAX_SAMPLES 128 frozen samples; MAX_RECORDS 128 claims, evidence artifact identities, total evidence records and citations per claim; MAX_STRING 4096 characters; MAX_DEPTH 32; MAX_NUMBER 1e100 absolute generic numeric magnitude; MAX_COLONIES 100000 per recorded count and per sample pooled/bounding sum. Bounds are checked before proportional sets, scans, parsing or computation. Byte equality passes, excess refuses before reading. The preparse JSON allowance counts root, commas and nonempty containers with an iterator; quoted punctuation can conservatively overcount. The remaining bundle allowance applies before each new JSON parse. Hardlink aliases consume each allowance once.

MAX_ITERATIONS 10000 bounds exact gamma series or continued-fraction convergence; QUANTILE_STEPS 96 bounds bisection. Failure to converge is poisson-convergence, never a normal fallback. Dilution fraction is finite in 1e-12 to 1 inclusive, volume in mL is finite in 1e-12 to 100 inclusive, frozen geometric ratio in 1.000001 to 1e6, duplicate ratio in 1 to 100, confidence level in 0.5 to 0.999. Public Poisson exposure is finite in 1e-24 to 1e12. Every declared integer is a real int, never bool, float or string. All numeric inputs must be finite. JSON refuses duplicate keys at every nesting level, NaN/Infinity, huge numbers, malformed UTF-8, non-object roots and excessive nesting with labelled ValueError findings. Identity strings are bounded and nonempty. No missing value is silently imputed.

## Pack-local schemas

All six schemas below are ordinary domain artifacts, not changes to existing receipts or sidecars. Every input has schema equal to the named schema and fixture equal to synthetic fixture. Object fields are exact, with unknown and missing fields refused.

- cfu-pack-v1: rules, counts and report artifact identities; evidence list of artifact identities; frozen_rules_sha256 equal to rules.sha256; real boolean frozen_before_counts_read true. Freeze is checked before count bytes are opened. Hash-bound declarations cannot establish historical order by themselves.
- cfu-rules-v1: nonempty unique sample_ids; nonempty plates; dilution_ratio; integer minimum_countable_plates in 1 to MAX_ROWS; duplicate_maximum_ratio; weighted_mean_rule equal to sum-counts-over-sum-volume-equivalents; interval_method equal to garwood-exact; interval_level; detection_rule equal to one-sided-poisson-upper. Each plate is exactly plate_id, sample_id, dilution_factor, volume_ml, minimum, maximum. IDs are unique and sample identity belongs to the frozen list. Integer range endpoints satisfy 1 <= minimum <= maximum <= MAX_COLONIES. Every sample needs rules. Distinct dilutions within each sample must be successive geometric fractions under the frozen ratio, compared with relative tolerance 1e-12 and no absolute tolerance.
- cfu-counts-v1: nonempty rows. Each row is exactly plate_id, sample_id, dilution_factor, volume_ml, count and flag. Every frozen plate appears exactly once. Identity, dilution and volume must match the frozen rule. Flag is observed, spreader, uncountable or unavailable. Observed count is an integer from 0 to MAX_COLONIES. Other flags require null count, never zero. An unavailable plate is an explicit row, never an omitted record.
- cfu-report-v1: rules_sha256, real boolean exploratory, countable_ranges mapping every plate ID to integer minimum and maximum; weighted_mean_rule, interval_method, interval_level; ordered samples; summary; nonempty headline; claims. Changed ranges require exploratory true and recomputation under those ranges; original rules and their hash are retained. All other computation rules remain frozen. Headline and claim wording are gated before count arithmetic so boundary findings are not hidden by later numerical errors.
- cfu-evidence-v1: records list. Each record is exactly id, kind, result, origin, source. Identity is unique across all evidence documents. Kind/result are nonempty text; source is a hash-bound artifact identity. Origin is internal, external, independent or preregistered. Non-internal source path AND hash must differ from every pack, rule, count, report and evidence-document identity; hardlink and content copies therefore cannot establish independence. This gate establishes only non-aliasing, not real-world independence.
- cfu-result-v1: validator-produced schema, fixture, status arithmetic-only, review unavailable, ordered stages, exploratory, inputs with path and sha256, computation, claims and limitations. It is unreviewed software output, never a passed review receipt. Expected.json wraps computation with the synthetic fixture label. Negative-cases.json contains synthetic fixture mutations, their target document/path, replacement or removal, and expected finding; tests materialize fresh hash-bound bundles for each mutation.

Each report sample is exactly sample_id, classification, included_plate_ids, excluded_plate_ids, integer total_colonies, volume_equivalent_ml, cfu_per_ml, log10_cfu_per_ml, interval, lod_upper_cfu_per_ml and lower_bound_cfu_per_ml. Quantified values must match the reference with relative tolerance 1e-9 and zero absolute tolerance, including near-zero values. Summary is exactly integer n, quantified, below_countable, above_countable and unavailable, plus mean_log10_cfu_per_ml or unavailable. n counts frozen samples, not plates. Every unavailable point estimate and log10 value is the literal string unavailable.

## 01-rule-freeze

Input: coordinator question, assumptions, sample/plate identities and intended claims. Call the decision framing in $cx-statistical-decision-analysis and existing $science-provenance to preserve rules.json plus SHA-256 as cfu-rules-v1 before counts admission. Output: immutable rules identity, the existing manifest plan step and one coordinator checkpoint. Fix dilution, volumes, ranges, countable minimum, duplicate ratio, weighted mean, exact interval method/level and detection rule before outcomes. Stop on essential missing choices; a later interpretation-changing revision needs a human decision and exploratory labelling. No per-stage permission prompt.

## 02-count-qc

Input: rules path/hash and counts.json path/hash. Call the pack validator's identity and table checks. Output: admitted cfu-counts-v1 ordinary artifact with preserved flags, exclusions and failed controls. Require unique IDs, nonnegative integer observed counts, geometric dilution consistency and frozen exposure. Spreader, uncountable and unavailable plates have null counts. Stop on failed controls; never drop a plate to obtain acceptance. The independent-Poisson, counting, pipetting and dilution assumptions are not validated by these software checks.

## 03-cfu

Input: admitted rules/counts identities and declared applied ranges. Call compute_cfu and poisson_interval through the one-argument CLI. Output: per-sample quantities inside cfu-report-v1 and cfu-result-v1. An observed plate enters the point estimate only when minimum <= count <= maximum. Check countable duplicate plates within each sample/dilution/volume group: max count / min count <= frozen duplicate ratio. Equality passes; failure stops pooling. Require the frozen minimum number of countable plates per quantified sample.

For countable plates, set k = sum(count), E = sum(volume_ml times dilution_factor), CFU/mL = k/E and log10 = log10(k/E). Use math.fsum for exposures and log summaries. At confidence L, alpha = 1-L, the equal-tail Garwood interval is GammaQuantile(k, alpha/2)/E to GammaQuantile(k+1, 1-alpha/2)/E, with lower zero only when the admitted Poisson count is zero. Gamma shape is integer and scale is one, equivalently chi-square quantiles divided by two. The stdlib implementation evaluates regularized gamma series/continued fractions and inverts with bounded bisection; there is no normal approximation. Independent Poisson counts with known exposures are assumptions, and observed countability selection can affect coverage. The interval is not a validation of those assumptions or unconditional post-selection coverage.

When no plate is countable and every observed plate is below its range, with no flagged rows, classify below-countable. For bounding only, sum the recorded below-range counts and exposures and report GammaQuantile(k+1,L)/E as the one-sided exact Poisson upper bound. This frozen detection convention gives -log(1-L)/E for all zero counts and is never zero. It is a model-based upper bound, not a validated assay detection limit or point CFU estimate. Set point CFU and log10 unavailable. Return interval method garwood-exact-one-sided, level L, lower unavailable and upper bound. Countable total_colonies and volume_equivalent_ml remain zero because no plate entered a point estimate.

When all plates are observed above their ranges, classify above-countable and report only max(maximum/(volume_ml times dilution_factor)) as a countable-range lower bound, not an exact Poisson confidence limit. Interval method is countable-range-bound, level unavailable, lower bound and upper unavailable. No point CFU, log10 or detection upper bound is given. A below/above mixture with no countable plate refuses as no-countable-bracket. If any plate is flagged and no countable plate exists, preserve unavailable rather than asserting a sample-wide below/above status. With valid countable plates, flagged and out-of-range plates are retained in excluded_plate_ids and contribute neither colonies nor exposure.

## 04-summary

Input: all computed sample records and original identities. Call reference summary checks. Output: sample n, four classification denominators and mean log10 over quantified samples only in cfu-report-v1. If there are no quantified samples, that mean is unavailable. Preserve bounds, missingness, failed controls, sensitivity needs, rejected alternatives and null results. Technical plate replicates never count as independent samples. No hypothesis test or significant biological result is produced.

## 05-handoff and claim gate

Input: report/evidence path-plus-hash identities, full rules, counts, failures and coordinator records. Call $science-provenance to register ordinary artifacts and separate claim-register entries; call $science-review for independent record, source and method review. Output: cfu-result-v1 plus the coordinator's existing checkpoint, claim register and later independent receipt. The pack never marks itself reviewed. Failed controls and negative results remain preserved in original inputs and caller-captured refusal JSON.

Claims are exactly id, kind, status, text and evidence IDs. Kind is descriptive or associational. Status is planned, supported, replicated, suggestive, conflicting, unsupported, withdrawn or unavailable. Empty evidence requires unavailable. Citing any unavailable kind or result requires unavailable even among observed evidence and for every other status. An unavailable claim cannot assert supported, replicated, suggestive or significant evidence. Replicated is always refused: one synthetic fixture cannot establish two independent studies. Every positive status (supported, replicated, suggestive) is refused when any citation's kind OR result denotes review, approval, computation, numerical agreement, truth, physical or clinical validity. Labels never replace evidence.

The conservative case-insensitive English whole-word/prefix wording families are: caus*, mechanis*, therap*, clinic*, efficac*, effective*, treat*, cure*, prevent*, recommend*, prescri*, bind*, affinit*, inhibit*, activat*, regulat*, drive/drives/driv*, induc*. Also refuse truth, physical validity, patient benefit, steril*, safe* and poten*. The check includes negations and is incomplete for unlisted paraphrases and other languages. Claim kind does not bypass wording. Association is never causality; computation is never physical or clinical validity; missing evidence is unavailable, never negative; review approval is never truth.

Human gates apply only before installation, restricted transfer, a new host, GPU/remote/heavy compute or an interpretation-changing choice. This reference uses no installation, network or remote behavior. Bounded claims and unresolved assumptions stay unavailable until coordinator-owned independent review; approval cannot turn them into truth.
