# Cell-count stages and local record contract

Every checked-in count, question and expected artifact is a synthetic fixture, establishing software arithmetic only. No assay, culture, biological, product or clinical validity follows.

## Invocation and immutable identities

Public entry points in codex_science.cell_count_viability_pack are validate_cell_count_viability_pack(bundle), compute_cell_count_viability(counts, rules, square_ids=None), and binomial_interval(live, total, level=0.95).

Run python3 scripts/validate_cell_count_viability_pack.py examples/workflow-cell-count-viability/pack.json. The CLI accepts one bundle argument, prints JSON on stdout and exits 0 on acceptance. All refusals, including missing, extra or unknown arguments, print JSON with status refused and finding on stderr and exit 2. Help is plain usage on stdout with exit 0. There is no output option. The validator writes nothing. Concurrent calls independently read immutable inputs. Interruption leaves all files unchanged and may truncate stdout; callers capture durable results atomically. It writes no file, ref or record.

Every artifact identity is exactly path and sha256: a canonical bundle-relative POSIX path and lowercase 64-hex SHA-256. The entry pack has no initial declared hash. Refuse absolute artifact paths, traversal, backslashes, noncanonical spellings, control characters, symlink components and special files. Walk from the filesystem root through O_DIRECTORY, O_NOFOLLOW and O_NONBLOCK directory descriptors; compare lstat/fstat device/inode for every ancestor, retain the final descriptor and compare the entire chain twice at the end. Open artifacts relative to pinned directories with O_NONBLOCK and O_NOFOLLOW; check lstat and descriptor fstat for regular files, identity, size and timestamps. Bound reads and check signatures after reading. Hash exactly the parsed bytes. Device/inode aliases share initial bytes and parsed JSON. At completion, re-read each distinct inode once, recheck all aliases and hashes, and refuse replacement, growth or ancestor swaps. Retain failures without repair.

## Limits and types

Named constants: MAX_BYTES 67108864 per regular artifact; MAX_TOTAL_BYTES 268435456 aggregate initial bytes across distinct inodes; MAX_ARTIFACTS 256 artifact paths; MAX_NODES 4000000 JSON values per bundle; MAX_ROWS 10000 count rows and generic JSON entries per container; MAX_SAMPLES 128 samples; MAX_CHAMBERS 256 chambers; MAX_SQUARES 64 recorded or applied square identities; MAX_RECORDS 128 claims, evidence documents, total evidence records and citations per claim; MAX_STRING 4096 characters; MAX_DEPTH 32; MAX_NUMBER 1e100 absolute generic numeric magnitude; MAX_CELLS 100000 per integer count, recorded per-sample sum and interval denominator. Check dimensions before sets, grids, allocation or per-item computation, including chamber count times square count at most MAX_ROWS. Byte-budget equality passes; excess refuses before reading. Preparse JSON allowance counts root, commas and nonempty containers with an iterator; quoted punctuation conservatively overcounts. Hardlink aliases consume raw-byte and parse allowances once.

MAX_ITERATIONS 1000 bounds beta continued fractions, QUANTILE_STEPS 96 bounds quantile bisection. Relatively singular denominators at or below 1e-14 times their arithmetic scale, failed convergence or zero interval denominator refuse; no normal fallback. Bisection must narrow its bracket to relative width 1e-12. Continued fractions converge at relative change 1e-14. All reported numerical comparisons and exposure matches use REL_TOL 1e-9, with zero absolute tolerance, including near-zero numbers. Countable thresholds and integer minima use inclusive integer comparisons. No exact floating-point match is required for reported quantities.

Volume per square is finite 1e-12 to 1 mL, predye dilution multiplier finite 1 to 1e6, each mixing part a real integer 1 to 1000, minimum cells a real integer 1 to MAX_CELLS, maximum chamber disagreement finite 0 to 2, confidence level finite 0.5 to 0.999. Every declared integer, including report counts and denominators, must be int, never bool, float or string. JSON refuses nested duplicate keys, malformed UTF-8, non-object roots, excessive nesting, NaN/Infinity and overflowing or huge numbers as labelled findings. Strings are bounded nonempty text without surrogate code points. No missing value is imputed.

## Pack-local schemas

These six schemas are ordinary domain artifacts, changing no existing receipt, sidecar or registry. Every input object has schema equal to its named schema and fixture equal to synthetic fixture. All object fields are exact; unknown or missing fields refuse.

- cell-pack-v1: rules, counts and report artifact identities; evidence list of artifact identities; frozen_rules_sha256 equal to rules.sha256; real boolean frozen_before_counts_read true. Check freeze before opening counts. Hash declarations cannot establish actual historical timing.
- cell-rules-v1: nonempty unique sample_ids; nonempty chambers; nonempty unique square_ids; volume_ml; dilution_factor; mixing_ratio; minimum_per_square; maximum_per_square; minimum_total_cells; maximum_disagreement; viability_definition live/(live+dead); interval_method clopper-pearson-exact; interval_level. Each chamber is exactly chamber_id, counter_id, sample_id. Chamber and counter IDs are globally unique; sample belongs to the frozen set and each sample has at least two chambers. The same recorded square set applies to all chambers. Mixing_ratio is exactly real integers sample_parts and dye_parts. Inclusive countable endpoints satisfy 1 <= minimum_per_square <= maximum_per_square <= MAX_CELLS. All controls and thresholds are fixed before counts.
- cell-counts-v1: nonempty rows, exactly one for every frozen chamber/square pair. Each row is exactly chamber_id, counter_id, sample_id, square_id, volume_ml, dilution_factor, mixing_ratio, live, dead, clumped. Identities and exposure match the frozen rules. Live/dead are both integers 0 to MAX_CELLS or both null for unavailable counts. Clumped is a real boolean, never zero or a missing field. Clumped recorded counts remain in the input and raw totals but never enter estimates. Null is unavailable, not a negative observation.
- cell-report-v1: rules_sha256; real boolean exploratory; square_ids; viability_definition; interval_method; interval_level; ordered samples; summary; nonempty headline; claims. Applied squares must be a nonempty subset of frozen recorded squares. A changed set or order requires exploratory true and recomputation while retaining original rules and all raw rows. Other controls stay frozen. Headline and evidence boundaries are checked before arithmetic, so their findings precede numerical findings.
- cell-evidence-v1: records list. Each record is exactly id, kind, result, origin, source; unique ID across documents; nonempty kind/result; origin internal, external, independent or preregistered; source a path-plus-hash identity. A non-internal source must differ in both path and hash from every pack, rule, count, report and evidence-document identity. Content copies and hardlink aliases cannot establish independence. Non-aliasing alone never proves independence.
- cell-result-v1: produced schema, fixture, status arithmetic-only, review unavailable, ordered stages, exploratory, inputs containing path and sha256, computation, claims and limitations. This is unreviewed software output, never a receipt. Expected.json wraps computation with the synthetic fixture label. Negative-cases.json stores synthetic target/path mutations, replacements or removals, and their expected findings; tests materialize a fresh hash-bound bundle for each case.

Each report sample is exactly sample_id, classification quantified or unavailable, included_squares and excluded_squares as ordered chamber/square pairs, integer recorded_squares, recorded_live, recorded_dead, integer usable_total, cells_per_ml, count_uncertainty, replicate_disagreement, viability and viability_interval. Recorded counts sum available raw rows, including exclusions; if no raw row is available both recorded totals are unavailable. Usable_total counts only applied countable unclumped rows. Concentration, viability, uncertainty and interval are unavailable unless all applied rows qualify and usable_total meets the frozen minimum. Uncertainty is exactly method poisson-standard-error, standard_error_per_ml and relative_standard_error. Interval is exactly method clopper-pearson-exact, level, lower, upper. Summary is exactly integer n, quantified, unavailable. n counts samples, never technical chambers or squares.

## 02-count-qc

Input: rules path/hash and counts.json path/hash. Call validator identity, exposure, integer and clumping checks. Output: admitted cell-counts-v1 ordinary artifact with all raw counts, unavailable rows, clumping flags and failed controls retained. Missing squares require explicit null rows; omission refuses. Measurement, mixing and Poisson/binomial assumptions remain unvalidated.

## 03-concentration-viability

Input: immutable rules/counts identities and applied square set. Call compute_cell_count_viability and binomial_interval through the one-argument CLI. Output: quantities inside cell-report-v1 and cell-result-v1. Every applied square must have available unclumped integer counts within the inclusive range; otherwise concentration and viability remain unavailable, even if other squares qualify. The minimum denominator applies to usable cells per sample. Preserve raw totals, eligibility lists and failed controls. An exploratory subset can exclude recorded squares but cannot invent new square identities.

For complete eligible chambers, compute their mean total cells per square, then disagreement as (maximum chamber mean minus minimum chamber mean) divided by the mean of chamber means. Equality to the frozen bound passes with relative tolerance only; an excess refuses pooling. A zero mean cannot define disagreement. Poisson or binomial zero denominators never produce significant-looking numbers.

Let k be the usable live plus dead count, q the number of eligible squares, V the frozen mL per square, D the predye dilution multiplier, s the sample mixing parts and d the dye parts. The factor is D times (s+d)/s divided by V. Concentration is (k/q) times the factor. Thus V of 0.0001 mL supplies the conventional 10000 chamber multiplier; mixing is applied exactly once and is separate from predye dilution. Independent-Poisson standard error is sqrt(k)/q times the factor, with relative standard error 1/sqrt(k). These are model-based uncertainties, not calibrated physical validation.

Viability is usable live/k, with equal-tail Clopper-Pearson limits BetaQuantile(live,dead+1,alpha/2) and BetaQuantile(live+1,dead,1-alpha/2), alpha being 1 minus the frozen confidence level. The all-dead lower bound is zero and all-live upper bound one; k zero refuses the public interval function. Evaluate regularized beta by bounded continued fractions and quantiles by bounded bisection using stdlib math only. No Wald or normal approximation. Conditional countability and clumping selection can alter coverage; review those assumptions separately. No interval is shown below the frozen minimum or for incomplete samples.

## 04-summary

Input: original identities and all per-sample quantities. Call reference summary checks. Output: cell-report-v1 sample n and quantified/unavailable denominators, retaining raw-count denominators, exclusions, nulls, failures and uncertainty. There is no hypothesis test, pooled biological mean or significant biological conclusion. The hand-derived synthetic fixture has A: 32 live, 8 dead, 40 usable, four squares, 400000 cells/mL, viability 0.8; B: four recorded live cells outside the range, unavailable estimates. ## 05-handoff and claim gate

Input: full rules/counts/report/evidence path-plus-hash identities, failures, environment/code identity, assumptions, reference ledger and coordinator records. Call $science-provenance to register ordinary domain artifacts plus separate existing claim-register entries, then $science-review for independent record, source and method review. Output: cell-result-v1 and coordinator-owned checkpoint, claim register and later independent receipt. The pack never marks itself reviewed. Retain failed controls, negative results and caller-captured refusal JSON.

Claims are exactly id, kind, status, text, evidence IDs. Kind is descriptive or associational. Status is planned, supported, replicated, suggestive, conflicting, unsupported, withdrawn or unavailable. Empty evidence requires unavailable. Citing any unavailable kind or result requires unavailable for every other status, including mixtures with observed evidence. An unavailable claim cannot assert supported, replicated, suggestive or significant evidence. Replicated always refuses because one synthetic fixture cannot establish independent studies. Positive statuses refuse any citation whose kind OR result denotes review, approval, computation, numerical agreement, truth, physical or clinical validity. Labels never replace evidence.

The conservative case-insensitive English whole-word/prefix families are: caus*, mechanis*, therap*, clinic*, efficac*, effective*, treat*, cure*, prevent*, recommend*, prescri*, bind*, affinit*, inhibit*, activat*, regulat*, drive/drives/driv*, induc*. Also refuse culture health, releas*, health*, truth, physical validity, patient benefit, steril*, safe* and poten*. The gate includes negations and is incomplete for paraphrases and other languages. Claim kind cannot bypass wording. Association is never causality; numerical agreement is never physical or clinical validity; missing records are unavailable, never negative evidence; review approval is never truth.

Human gates apply only before installation, restricted transfer, new hosts, GPU/remote/heavy compute or interpretation-changing choices. This pack uses none of that external execution. Bounded claims and unresolved assumptions stay unavailable pending coordinator-owned independent review; approval never makes them truth.
