# Synthetic CRISPR stages and local records

## Invocation and immutable identities

`python3 scripts/validate_crispr_screen_pack.py BUNDLE` takes exactly one bundle JSON path, prints `crispr-result-v1` JSON to stdout and writes no files. Missing, extra and unknown arguments produce a JSON refusal on stderr and exit 2; `--help` gives plain usage on stdout and exit 0. All refusals are labeled ValueErrors (`code: explanation`), represented by CLI `{status: "refused", finding: "code: explanation"}`. There is no output option, install, transfer, network, GPU or remote behavior.

Each referenced artifact is `{path, sha256}` with canonical bundle-relative POSIX spelling and a lowercase SHA-256 of the bytes actually parsed. Absolute paths, traversal, backslashes and symlink components are refused. The bundle itself may be supplied by an absolute local path, but its full ancestor chain must contain real directories. All root ancestors are walked with directory descriptors and O_NOFOLLOW; their device/inode pairs are retained. Artifacts are opened relative to the pinned root, with lstat, O_NONBLOCK|O_NOFOLLOW, fstat regular-file and identity/size checks, a bounded read and a post-read fstat. Hardlink aliases share one parsed byte snapshot. Final byte/hash checks and full ancestor-chain checks refuse replacement or mutation, including a replaced parent retaining the bundle inode. The final hash recheck rereads each distinct artifact once; it does not parse it again.

No output record or review attestation is written. Concurrent calls read the same immutable inputs independently. A kill leaves inputs unchanged; redirected stdout may be incomplete and must not be registered until a successful parse and exit. The producer must publish its own run artifacts atomically outside this validator.

## Bounds before scaled work

Module constants: MAX_BYTES=64 MiB per artifact; MAX_TOTAL_BYTES=256 MiB across distinct inodes; MAX_TOTAL_NODES=4,000,000 conservative bundle-wide JSON values; MAX_ARTIFACTS=128 unique paths; MAX_DEPTH=32; MAX_TEXT=4096 characters; MAX_ITEMS=20,000 per JSON container; MAX_GUIDES=10,000 library or count rows; MAX_GENES=2000 distinct genes; MAX_SAMPLES=64; MAX_VALUES=200,000 guide-by-sample cells; MAX_DRAWS=2000; MAX_DRAW_WORK=2,000,000 (sum of eligible guide counts times draws); MAX_CLAIMS=100; MAX_SUPPORT=100 per claim; MAX_NUMBER=1e100; MAX_COUNT=1,000,000,000,000 per count. Root paths are bounded by MAX_TEXT. At most MAX_SAMPLES squared concordance entries are admitted; computation uses each unordered replicate pair once.

The preparse value allowance is the conservative upper bound `1 + commas + nonempty containers`, counted with a streaming regex iterator, including punctuation inside strings. It is enforced before JSON allocation. After parsing, depth, string/key length and container sizes are checked. Duplicate keys, non-object roots, malformed UTF-8/JSON, huge numbers, NaN/Infinity and bool-as-number are refused. All integer fields (including every schema_version, count, timepoint, guide_count, seed and draw count) require a real int, never bool, float or numeric string. Domain dimensions are checked before sets, matrices or permutation loops. Finite zero-variance vectors/nulls and insufficient paired guides are refused; no exception is swallowed to manufacture successful draws. Each permutation samples validated finite control values, so a data-invalid draw cannot occur in this implementation.

## Pack-local schemas

Every domain record has `schema` (the exact name below), real integer `schema_version: 1`, and `fixture: true`. All listed fields are required; unknown fields are refused. See checked-in synthetic fixture JSON for concrete values.

- `crispr-pack-v1`: `stages` (five IDs in order), `inputs` (exactly frozen_rules, rules, library, design, counts, report identities), `frozen_sha256`, `frozen_library_sha256`, `frozen_design_sha256`, boolean `exploratory`, `study_outputs` (identities), `claims` (local claim objects). Frozen hashes bind original rules/library/design identities. The current rules must equal frozen rules unless exploratory.
- `crispr-rules-v1`: `contrast` (two distinct condition strings in baseline/selected order), integer `minimum_total_reads` (1 to MAX_COUNT times MAX_GUIDES), `minimum_detection_fraction` (0 to 1 inclusive), `normalization` (total-count or median-of-ratios), positive `pseudocount` (1e-12 to MAX_COUNT), `aggregation` (median-guide-log2), integer `minimum_guides` (1 to MAX_GUIDES), integer `minimum_controls` (2 to MAX_GUIDES), integer `minimum_replicates` (2 to MAX_SAMPLES/2), `concordance_threshold` (-1 to 1), positive `fold_change_threshold` (1e-12 to 100), `alpha` (1e-12 to 1), `multiple_testing` (benjamini-hochberg), integer `permutation_seed` (0 to 2^32-1), integer `permutation_count` (1 to MAX_DRAWS). The fixture freezes 1000 reads, detection 0.8, total-count, pseudocount 1, three guides, four controls, two replicates, Pearson 0.9, absolute fold change 1, alpha 0.05, seed 1729 and 99 draws.
- `crispr-library-v1`: nonempty `guides`, each `{id, gene, non_targeting}`. IDs are unique strings; non_targeting is boolean; controls have null gene, other guides a nonempty gene string. At least one gene and minimum_controls controls are required.
- `crispr-design-v1`: nonempty `samples`, each `{id, condition, replicate, timepoint}`. All IDs/conditions/replicates are bounded strings. Sample IDs and per-condition replicate IDs are unique. Both contrast conditions have the same replicate IDs with at least minimum_replicates; each condition has one integer timepoint (0 to MAX_COUNT), baseline strictly earlier than selected. Matched IDs identify separate fixture trajectories, not a claim of experimental independence.
- `crispr-counts-v1`: `sample_ids` exactly matching design order; nonempty `rows`, each `{guide_id, counts}`. Guide IDs are unique and in the library. Each count vector matches sample width and contains only bounded non-negative integers. Absent library rows remain missing: they affect detection/coverage and cannot contribute eligible gene guides. Controls must be present and positive in every sample.
- `crispr-report-v1`: `multiple_testing`, `library_coverage`, `qc`, `normalization_factors`, `guide_fold_changes`, `concordance`, boolean `pooled`, `genes`. QC rows are `{sample_id, total_reads, detection_fraction, zero_fraction, gini, failures}`. Guide rows are `{guide_id, replicate_log2_changes, log2_fold_change}`. Concordance rows are `{contrast, replicates, pearson, passed}`. Gene rows are `{gene_id, guide_count, status, reasons, log2_fold_change, p_value, q_value, significant}`. All values must match the independent reference recomputation within 1e-12 relative/absolute tolerance for floats; integer and boolean types remain exact. Observed gene status is observed, with boolean significant; unavailable rows have null effect/p/q/significant and explicit reasons. Failed QC gives null normalization factors and empty guide/concordance arrays. The validator checks missing BH, unavailable-as-negative, failed-sample inclusion and discordant pooling before generic arithmetic mismatch.
- `crispr-evidence-v1`: bounded strings `kind`, `result`, `origin`, `gene_id`. Origin is study/external/independent/preregistered. Positive claim evidence must have kind guide-count-observation and result gene-level-association, refer to that same gene, and never declare computed agreement or review approval in either field. Non-study evidence may not share a path OR hash with any input or declared study_output. These declarations cannot prove real independence.
- `crispr-result-v1`: read-only return object with `stages`, `evidence_level: offline-arithmetic-only`, `review: unavailable`, boolean `exploratory`, `input_identities` (all admitted paths/hashes), `report`, `claims`, and `limitations`. It cannot self-attest review.

Local claims have exactly `{id, kind, text, status, support, gene_id}`. IDs are unique bounded strings. Kind is descriptive/associational. Status uses the existing claim status vocabulary: supported, replicated, suggestive, planned, conflicting, unsupported, withdrawn, unavailable. These local objects are ordinary domain content; the coordinator separately registers claims with the existing claim-register schema. An empty support list requires unavailable status; ANY unavailable record kind or result forces unavailable status even in a mixed list. Replicated is always refused for positive claims in this single synthetic study. A positive claim also needs a reference gene passing BH and fold change; exploratory changes permit only suggestive positive status. Labels alone cannot support a claim.

The claim gate is a conservative English lexical check: case-insensitive whole words and prefix families caus*, mechanis*, therap*, clinic*, efficac*, effective*, treat*, cure*, prevent*, recommend*, prescri*, bind*, affinit*, inhibit*, activat*, regulat*, drive/drives/driv*, induc*. It also refuses essential*, drug target, physical validity, biological validity and truth. Unavailable text additionally refuses supported, replicated, suggestive and significan*. Negations are included. This check is incomplete for paraphrases and other languages; it does not replace independent semantic review. Association is never causality; computed agreement never establishes physical or clinical validity; review approval is never truth.

## 01-freeze: identities before outcomes

Input: pack path and byte hash; frozen_rules, rules, library and design paths plus SHA-256. Calls: `$cx-statistical-decision-analysis` for framing and the pack validator for strict field checks. Read frozen rules, validate/hash them, compare the current rules, then bind library/design hashes before loading counts. Output: immutable crispr-rules-v1, crispr-library-v1 and crispr-design-v1 ordinary artifacts. Stop: missing hashes, unsupported aggregation/normalization or an unlabelled changed rule. The order is enforced in code, but hashes cannot prove historical preregistration. Human gate only for interpretation-changing choices, new installations/hosts/transfers or heavy/remote/GPU compute; none occurs in this offline reference.

## 02-count-qc: identity and controls

Input: frozen library/design/rules identities plus counts path/hash. Calls: `_tables` through the public validator/reference_computation. Output: QC portion of crispr-report-v1. Require unique library/count guides, library membership, integer counts, exact columns and detected controls. Total reads sum all counts including controls. Detection is positive library guides/library size; zero fraction is one minus detection; overall library coverage is count rows/library size. Gini is sum((2*i-n-1)*sorted_count_i)/(n*total) for one-based i. Missing rows are zero only for this QC denominator; they are omitted from guide changes/concordance and are never observed gene evidence. Failed reads/detection remain visible and disable all gene summaries. Equality to a threshold passes; do not lower it after seeing failures.

## 03-guide-changes: normalized matched changes

Input: unchanged count, library, design and rule identities. Calls: reference_computation and pearson in the pack module. Output: normalization, guide-change and concordance fields of crispr-report-v1. Total-count factors are sample total/median sample totals. Median-of-ratios uses geometric means of all-positive library rows, then per-sample median ratios. Divide counts by factors before adding pseudocount. For each matched replicate compute log2((selected+p)/(baseline+p)), then subtract its non-targeting median. Guide pooled change is the median of its matched-replicate changes. Pearson compares complete guide vectors between each unordered replicate pair for the frozen condition contrast; scaled centered vectors avoid tiny-value variance underflow. Too few guides or zero variance refuses. Below threshold disables pooling; no replicate is silently removed. Failed sample QC skips this computation and preserves unavailable results.

## 04-gene-summary: full-family correction

Input: unchanged handoffs and guide/concordance values. Calls: reference_computation and benjamini_hochberg. Output: complete crispr-report-v1 plus submitted report identity for comparison. An eligible guide is present and positive in every sample. A gene needs minimum_guides eligible guides and at least as many controls as guides. Median pooled guide changes is its statistic. With Random(permutation_seed), in frozen library/gene order draw permutation_count control subsets of that same size without replacement and take their median. Empirical two-sided p=(1+number with absolute median >= absolute gene change)/(1+draws); comparisons within 1e-12 relative/absolute tolerance count as ties. Controls are the centered pooled guide null; zero-variance null is refused. BH includes every observed gene, including nonsignificant ones; unavailable genes are excluded explicitly, with their rows retained. Significant requires q<=alpha AND absolute effect>=fold_change_threshold. Failed sample/concordance or insufficient guides/null makes all inferential fields null and unavailable, never negative. A submitted report lacking correction, pooling discordant replicates or including failed samples is refused. Retain failure artifacts; correct the defect before one bounded retry.

## 05-handoff: claims and independent review

Input: all prior identities, computed report, local claims, every cited evidence identity and declared study_output. Calls: `$science-provenance` and coordinator-owned `$science-review`. Output: crispr-result-v1, registered ordinary domain artifacts and separate existing claim-register entries. Preserve controls, denominators, nonsignificant/null/failed/unavailable rows, conflicts, assumptions, source dependencies and rejected alternatives. Record the smallest discriminating next observation: an independently reviewed synthetic rerun or a separately authorized real-screen design, never target nomination. Only the coordinator assigns rigor and registers independent review. One checkpoint uses all five ordered IDs; no self-review or engine is added.
