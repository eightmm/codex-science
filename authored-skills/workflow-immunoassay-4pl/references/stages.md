# Synthetic immunoassay 4PL stages and local records

Every checked-in plate, expected result and negative case is a synthetic fixture. This reference controls an offline arithmetic check and provides no scientific evidence, assay validation or review approval.

## Invocation and identities

Public entry points are `codex_science.immunoassay_4pl_pack.validate_immunoassay_4pl_pack(path)`, `compute_immunoassay(plate, design)` and `four_pl(x, parameters)`. Parameters are ordered a,d,c,b. The Python validator returns an unreviewed `immunoassay-result-v1`. In-memory computation validates its plate and design and returns the computation object described below.

Run `python3 scripts/validate_immunoassay_4pl_pack.py examples/workflow-immunoassay-4pl/pack.json`. Exactly one bundle argument is accepted. Success prints JSON on stdout, exits 0 and writes no files. Refusals, including missing, extra and unknown arguments, print JSON with `status: refused` and `finding` on stderr and exit 2. `--help` prints plain usage on stdout and exits 0. There is no output-path option or automatic repair.

Every handoff identity is exactly an object with `path` and `sha256`: a canonical bundle-relative POSIX path and lowercase 64-hex hash of the raw bytes actually parsed. Absolute paths, traversal, repeated separators, dot components, backslashes, colons, symlinks and escaping paths are refused. The bundle entry is initially unhashed; its digest is returned with all admitted identities. Root paths are walked from the filesystem root through pinned directory descriptors using O_DIRECTORY and O_NOFOLLOW; lstat and fstat identities of every ancestor are compared. The full ancestor chain is checked again before and after the final recheck, including parent replacement that preserves the bundle inode. Reads are relative to pinned descriptors, with lstat regular-file admission, O_NONBLOCK and O_NOFOLLOW, fstat identity/size checks, bounded read(size+1), post-read signature checks and hashing of those exact bytes. Initial artifacts are read and parsed once per device/inode, including hardlink aliases. At the end each admitted path is reopened and each distinct inode read once to recheck hashes. A FIFO or changed file cannot silently become accepted input.

Limits are module constants: MAX_BYTES is 67108864 per regular file; MAX_TOTAL_BYTES is 268435456 across distinct admitted inodes; MAX_TOTAL_VALUES is 4000000 across parsed JSON inputs; MAX_ARTIFACTS is 128 paths; MAX_ITEMS is 20000 per generic JSON container; MAX_WELLS is 384 per plate/map or reported sample collection; MAX_STANDARDS is 32; MAX_CLAIMS and MAX_RECORDS are 128 each (records also aggregate across wrappers); MAX_TEXT is 4096 characters; MAX_DEPTH is 32; MAX_ITERATIONS is 200; MAX_NUMBER is 1e100. Bounds precede proportional work. Aggregate size admission uses fstat size before any new file read; hardlinks share bytes and parse budget. The JSON value upper bound is one plus comma count plus nonempty-container count, calculated before parsing with a non-consuming lookahead iterator, without a match list. Equality passes; over-limit, empty required collections, zero budgets, malformed dimensions and numeric types are refused. Optional evidence and claim lists may be empty. Strict parsing rejects duplicate keys at every depth, non-object roots, NaN/Infinity, huge numbers, invalid UTF-8 and excessive nesting. Every integer, including replicate counts, iteration cap, reported iterations and degrees of freedom, is a real int, never bool, float or numeric string.

## Pack-local schemas

These six records are ordinary artifacts. They do not extend a global contract. Input objects have exact fields; all carry `schema` with the named version and `fixture: synthetic fixture`. The result has that same fixture label.

- **immunoassay-pack-v1**: `stages` equal to the five ordered IDs; `design`, `plate` and `report` artifact identities; `evidence` list of wrapper identities; `frozen_design_sha256` equal to the admitted design hash; boolean `frozen_before_responses` true. Validate the freeze before reading responses. A hash and boolean do not prove historical freezing.
- **immunoassay-design-v1**: nonempty `analyte` and `units`; `standards` (5 to MAX_STANDARDS ascending unique levels); `plate_map`; `blank_rule` none or subtract-mean; `parameterisation` increasing-a-d-c-b; `weighting` uniform; `fitting`; `recovery_band`; `maximum_cv`; `parallelism_band`; `standard_exclusion` none. Each standard is exactly id, concentration, replicates. Concentrations are in [1e-12,1e6]; replicates are integers in [2,MAX_WELLS]. Each map row is well, kind, id, dilution. Kind is blank, standard or sample; all well IDs are unique; dilution is in [1,1e6] and must be 1 for blanks/standards. At least one blank and one sample group are required, each with at least two replicates; standard counts must match their frozen counts. Groups are keyed by kind, id and dilution.
- **immunoassay-plate-v1**: `analyte`, `units` and `wells`. Both identities must match the design. Every well is exactly well,response; responses are finite numbers in [0,100], IDs are unique and map coverage is complete with no extra wells. These are synthetic optical densities, never patient observations.
- **immunoassay-report-v1**: `blank_rule`, real boolean `exploratory`, `computation`, `headline` and `claims`. The blank rule must equal the frozen rule unless exploratory is true; exploratory recomputes using the changed rule while preserving the original design. A report must match recomputation with relative tolerance 1e-8 only, with no absolute tolerance for small distinct values. Integers and flags match exactly. Outside-range concentration fields must be null and no reported concentration may exceed the accepted range.
- **immunoassay-evidence-v1**: `records`, each exactly id,kind,result,origin,source. IDs are unique across wrappers; kind/result are nonempty text, including unavailable when appropriate. Origin is internal, external, independent or preregistered. Source is a checked artifact identity, or null only when kind/result is unavailable. External/independent/preregistered source paths and hashes must differ from all own design, plate, report, pack and wrapper identities. Labels and distinct hashes do not prove actual independence.
- **immunoassay-result-v1**: `status` accepted, `review` unavailable, boolean `exploratory`, recomputed `computation`, pack-local `claims` and immutable `inputs` identities, plus schema and fixture. Accepted means internal arithmetic/report consistency, including faithfully reported QC failures. It never means an assay or claim passed scientific review.

Fitting is exactly method,start,tolerance,iteration_cap,damping: method levenberg-marquardt; start is four parameters a,d,c,b with 0<=a<d<=100, c in [1e-12,1e6], b in [1e-6,20]; tolerance in [1e-12,1e-4]; integer iteration_cap in [1,MAX_ITERATIONS]; initial damping in [1e-12,1]. Recovery and parallelism bands each contain two numbers in [0,1000] with lower<=1<=upper; equality is included. Maximum CV is a percentage in [0,100]. These fixture controls are software examples, not recommended assay criteria.

The computation object is exactly fit,blank_mean,blank_cv,blank_cv_flag,used_standards,standards,quantifiable_range,samples,parallelism,qc_passed. Fit has parameters,standard_errors,converged,iterations,sse,degrees_of_freedom. Standard rows have id,concentration,response_mean,cv,cv_flag,back_calculated,recovery_ratio,accepted. Sample rows have id,dilution,response_mean,cv,cv_flag,status,concentration. Parallelism rows have id,ratios,status. Status is passed, failed or unavailable for parallelism, and in-range, below-range or above-range for samples. All flags are booleans. Failed measurements remain present; no filtering is permitted to improve the fit.

Claim proposals are exactly id,kind,status,text,evidence; these are pack-local proposals, not new claim-register fields. Kind is descriptive or associational. Status is planned, supported, replicated, suggestive, conflicting, unsupported, withdrawn or unavailable; evidence is a unique bounded list of admitted record IDs. IDs/status/kind and evidence keys must be strings before membership checks. Any cited unavailable record/source, alone or mixed with observed records, requires unavailable status for every other status. Empty evidence also requires unavailable. Unavailable text cannot assert supported, replicated, suggestive or significan* evidence. Replicated is always refused because one synthetic plate cannot establish independent replication.

All positive statuses (supported, replicated, suggestive) are refused when either the declared evidence kind or result contains review, approv, comput, numer, agreement, truth, physical or clinic, even when another field says observed. Source kind/result fields are checked too; unavailable sources require unavailable status and local report/result schemas count as computed evidence even if a wrapper says observed. Wording is checked independently of the claim kind. The case-insensitive whole-word prefix families are caus*, mechanis*, therap*, clinic*, efficac*, effective*, treat*, cure*, prevent*, recommend*, prescri*, bind*, affinit*, inhibit*, activat*, regulat*, drive/drives/driv*, induc*. Here the star means a word-character suffix. The gate also refuses diagnos*, patient*, truth, physical validity and cutoff/cut-off wording. It applies to every claim and headline, including negations, and is conservative and incomplete; independent review must assess unlisted paraphrases. Association is never causality, numerical agreement never establishes physical or clinical validity, approval is never truth, and absent evidence is unavailable rather than negative evidence.

## 01-freeze: immutable rule admission

Input identities: pack and design path/hash. Calls: validate_immunoassay_4pl_pack and existing `$cx-statistical-decision-analysis` for contract context only. Output artifact/schema: frozen immunoassay-design-v1 and its identity in immunoassay-pack-v1. Freeze analyte, units, standard dilution series/replicates, map, blank rule, parameterisation, uniform weighting, starts, tolerances, damping, iteration cap, recovery/CV/parallelism criteria and no-exclusion rule before outcomes. Failure: design-freeze, stage-order, curve-parameters, standard-exclusion, fit-method or input findings; retain the refusal and original rules. Human decision gate only for interpretation-changing choices or the external actions listed below.

## 02-qc: response identities and controls

Input identities: unchanged frozen design and plate path/hash. Calls: validator and compute_immunoassay; no extraction, network or instrument access. Output artifact/schema: admitted immunoassay-plate-v1 with QC in immunoassay-result-v1. Require finite OD, map completeness, unique IDs, blanks, matching analyte/units and minimum replicates. Subtract the mean of all blanks only under subtract-mean; blanks always remain present. Compute response CV as 100 times sample SD divided by absolute mean; blanks use raw responses, other groups use corrected responses. Identical zero replicates have CV 0; zero mean with nonzero SD is degenerate-replicates and cannot yield a number. Failure: duplicate-well, missing-blanks, missing-samples, insufficient-replicates, standard-series, insufficient-standards, plate-map, units-mismatch, analyte-mismatch or input findings. Preserve failures; no new human gate for admitted offline input.

## 03-fit: constrained arithmetic

Input identities: design, plate and report path/hash. Calls: standard-library compute_immunoassay and the thin CLI. Output artifact/schema: checked immunoassay-report-v1 and immunoassay-result-v1. Model is y=a+(d-a)/(1+(c/x)^b), increasing in x. Fit all standard replicates with uniform residual weighting. Levenberg-Marquardt uses the analytic Jacobian, diagonal damping and a four-dimensional pivoted linear solve; reject trial steps outside the parameter domain. Decrease damping by three on improvement, increase by ten otherwise. Stop on gradient maximum <= frozen tolerance or improving step maximum after division by max(1,abs(parameter)) <= tolerance. Never retry with alternate starts. A cap failure is fit-not-converged; singular information or zero standard response variance is degenerate-fit. Sample n is the number of standard replicate responses, greater than four. Parameter SE is sqrt(diagonal(inverse(J'J))*SSE/(n-4)); noiseless residual uncertainty is only a local arithmetic diagnostic, not calibrated assay uncertainty. Dilution, standard preparation and model error are not included.

Back-calculate each standard mean with x=c*exp((log(y-a)-log(d-y))/b), requiring a<y<d. Retain its recovery ratio to frozen concentration and CV flag; accept only within the inclusive recovery band and maximum CV. Every standard remains in fitting. Require at least two accepted levels, with quantifiable range from lowest to highest; otherwise quantifiable-range. Invert unknown group means only between the fitted responses at those endpoints, using relative tolerance 1e-10 solely for floating-point endpoint ties; clamp a numerical endpoint tie to that endpoint. Outside responses yield below-range or above-range and null concentration, never extrapolation. Positive concentration means in-well interpolation only. Two or more in-range dilutions with passing CVs permit ratios (interpolated concentration times dilution)/(first interpolated concentration times first dilution), sorted by dilution. All ratios must lie in the frozen inclusive parallelism band. A missing second dilution, out-of-range dilution or flagged replicate group makes parallelism unavailable; a failed ratio remains failed. No dilution-adjusted concentration claim is produced. QC passes only with passing blank/standard/sample CVs, all accepted standards and no failed parallelism. Unavailable parallelism remains explicit.

The noiseless synthetic fixture uses a=.1,d=2.1,c=4,b=1, standards 1,2,4,8,16,32, each duplicated; add .05 raw blank. Unknown A at dilutions 1 and 2 has in-well values 8 and 4, so the corrected ratio is 1. The low/high means correspond to .25 and 64 and must never receive concentrations. Noisy pairs add minus/plus .002 OD per nonblank pair, retaining the same means. Their standard SSE is 12*.002^2=.000048 with eight residual degrees of freedom. Tests independently derive the Jacobian covariance by cofactors and verify CV as sqrt(2)*.002/mean*100. This is numerical agreement only.

## 04-summary: preserve failures

Input identities: unchanged design, plate, report, evidence wrappers and sources. Calls: validator's exact report comparison and evidence/claim checks. Output artifact/schema: immunoassay-result-v1 or a caller-captured refusal. The validator rejects extrapolation, fit-not-converged, curve-parameters, standard-exclusion, parallelism-ignored, replicate-cv-ignored, post-hoc-blank, reported-result and input findings. Preserve the complete failing controls and null results instead of deleting rows. Evidence failures include external-alias, unavailable-evidence, non-evidence-support, claim-replication, claim-overreach, unavailable-positive and missing-evidence. Availability/evidence failures precede the later wording gate. No new human gate; an interpretation-changing revision preserves the original freeze and requires explicit exploratory scope.

## 05-handoff: bounded claims and review

Input identities: every admitted path/hash, reference-use identities and caller-captured result/logs. Calls: `$science-provenance` ordinary artifact registration, separate existing claim-register entries and `$science-review` record/source/method modes. Output artifact/schema: existing coordinator-owned artifacts/claims/review records, with no new fields. The coordinator owns rigor classification and independent receipt registration. Review remains unavailable in this pack. Preserve normalized assumptions, dependencies/conflicts, rejected alternatives, failed controls, negative results, unavailable observations and the smallest falsifiable next step: independent checking of the frozen curve and dilution controls.

Use one checkpoint per run and plan entries exactly id,description,status from plan.json. Human gates apply only before installation, restricted transfers, new hosts, GPU/remote/heavy compute or interpretation-changing choices. None is authorized here. Runtime validation writes no files, records or refs. A second concurrent call reads the same immutable inputs; a kill leaves inputs unchanged and may truncate stdout. Coordinators capture durable results atomically in their existing system. All checked-in fixture/report/expected files are static and never rewritten by the validator; no partial multi-file publication occurs.
