# Stages and local records

All checked-in examples are redistributable synthetic fixtures. No fixture is a measured animal result. Output states arithmetic summaries of the supplied profiles only. These local records are ordinary artifacts; claim-register entries remain separate. No existing manifest, receipt or global schema changes.

## Invocation and immutable identities

`python3 scripts/validate_pk_nca_pack.py BUNDLE` accepts one JSON bundle argument and prints one JSON object. Success exits 0 with `status: arithmetic-only`, `review: unavailable`; a labelled refusal exits 2 with `status: refused` and `error`. No output option, network or writes. The library entry points are `validate_pk_nca_pack(bundle)` and `compute_nca(profiles, rules)` in `src/codex_science/pk_nca_pack.py`. The latter accepts already-decoded records and checks their shapes and dimensions, but does not check file identities.

Every identity is exactly `{path, sha256}` with a canonical bundle-relative path and lowercase SHA-256 of the bytes parsed. No absolute path, backslash, parent traversal, symlinked component or escape is admitted. Freeze identities before profile admission. Each ancestor is opened through a pinned directory descriptor with O_DIRECTORY and O_NOFOLLOW, checked with lstat/fstat identity. Artifacts are read relative to the pinned root, with O_NONBLOCK/O_NOFOLLOW, lstat/fstat regular-file/identity/size checks and a bounded read. Initial bytes are read and parsed once per inode, including hardlink aliases. Hashes and directory identities are checked again at the end; a replacement is refused. This is race detection, not a transactional filesystem snapshot.

Limits, enforced before scaling work: MAX_BYTES = 64 MiB per artifact; MAX_TOTAL_BYTES = 256 MiB across distinct inodes; MAX_JSON_VALUES = 4,000,000 estimated JSON values per bundle before decoding; MAX_ARTIFACTS = 128 path identities; MAX_ROWS = 10,000 aggregate profile points; MAX_ITEMS = 20,000 entries per JSON container; MAX_SUBJECTS = 128; MAX_POINTS = 1,024 per subject and per schedule/window; MAX_RECORDS = 128 claims, evidence records or support IDs; MAX_STRING = 4,096 characters; MAX_DEPTH = 32; MAX_NUMBER = 1e100. Time, dose and concentration scalars are additionally bounded to 1e12. JSON allowance uses `1 + commas + nonempty containers`, a conservative upper bound including punctuation inside strings. Duplicate JSON keys, non-object roots, NaN/Infinity, huge numbers, bool-as-number, wrong types and deep nesting are refused. Every declared integer (counts and minimum terminal points) is a real int; schema names are versioned strings, not integer fields. Limits are pack-local and affect no existing stored-record class.

## Pack-local schemas

All records below require the exact field sets shown. Every top-level record has `schema` equal to its listed name and `fixture: "synthetic fixture"`. Unknown fields are refused. All reference inputs deliberately remain synthetic; the coordinator must establish applicability before any adaptation to measured data.

- `pk-nca-pack-v1`: `schema, fixture, stages, frozen_rules, rules, profiles, report, evidence`. `stages` is the five ordered IDs. Remaining fields are path-plus-hash identities. `frozen_rules` identifies original rules, `rules` effective rules; both are parsed and hashed before profiles. Different hashes require the report's exploratory label. The reference cannot independently prove historical preregistration.
- `pk-nca-rules-v1`: `schema, fixture, subject_unit, system, route, nominal_dose, dose_unit, time_unit, concentration_unit, sampling_schedule, lloq, below_limit_rule, substitution, trapezoid, terminal_window, minimum_terminal_points, minimum_adjusted_r_squared, maximum_extrapolated_fraction, parameters`. `system` is animal or in-vitro. Dose is positive; units and route are nonempty. Schedule and terminal window are nonempty strictly increasing numeric times; window times must be scheduled. Minimum points is an integer 3..MAX_POINTS. Adjusted-fit threshold and extrapolation fraction are in [0,1]. `trapezoid` is `linear-up/log-down`. `below_limit_rule` is `censored` (null substitution) or `substitute` (explicit numeric 0..lloq). `parameters` is exactly `cmax, tmax, auc_0_tlast, lambda_z, half_life, auc_0_inf, extrapolated_fraction` in that order.
- `pk-nca-profiles-v1`: `schema, fixture, subjects`. Each subject: `subject_id, concentration_unit, time_unit, points`. Each point: `time, concentration, censored`. Subjects are unique; points are nonempty and strictly increasing with scheduled times; missed scheduled samples are allowed but never invented. Censored measurements have null concentration, otherwise concentrations are finite, non-negative and at least lloq. Recorded units must match rules for every subject. An entirely censored subject is refused. An interior censored gap before the last quantified observation needs the frozen substitute rule. A censored tail is retained but ends neither the measured AUC nor the regression window.
- `pk-nca-report-v1`: `schema, fixture, rules_sha256, exploratory, computation, claims, statement`. Rules hash must match effective rules; exploratory is boolean. `statement` is exactly `Arithmetic summaries of the supplied profiles only.` `computation` has `subjects, group`; subject fields: `subject_id, cmax, tmax, cmax_source, auc_0_tlast, terminal_points, adjusted_r_squared, lambda_z, half_life, auc_0_inf, extrapolated_fraction, status, reasons`. Cmax source is observed. Terminal point count is integer. Missing diagnostics use unavailable; unreliable half-life/AUC(0-inf) use unreliable. Status is reliable or unreliable; reasons list named failed criteria. Group: `subject_ids, n, parameters`; n is integer. Each parameter: `n, geometric_mean, range`. Range is [minimum,maximum] or unavailable; geometric mean is unavailable for an empty group or a nonpositive parameter. Every reported value is compared with the reference (numeric tolerance 1e-9 relative, 1e-12 absolute); counts and subject lists match exactly.
- `pk-nca-evidence-v1`: `schema, fixture, records`. Each record: `id, kind, result, origin, source`. IDs are unique bounded strings. Origin is internal, external, independent or preregistered; source is a checked path-plus-hash identity. Non-internal origins must differ by both path and hash from every study input/output identity and the evidence artifact. These checks cannot establish true independence. Claim entries are local copies shaped `id, kind, status, text, evidence` (record IDs), not additions to the global claim-register schema. Kind is descriptive, associational, causal or confirmatory; causal is refused. Status uses existing statuses; unavailable evidence requires unavailable status, replicated is always refused here.
- `pk-nca-result-v1`: `schema, fixture, status, review, stages, exploratory, rules_sha256, computation, statement`. The CLI returns this object without persisting it. Status is arithmetic-only and review unavailable. Computation is the same checked shape as above.

## 01-rule-freeze

Accepted identity: original `rules.json` path and hash and optional separately named effective rules. Use `$cx-statistical-decision-analysis` for framing, existing `references/plan.json` manifest step shape and `$science-provenance` for identities. Output: `pk-nca-rules-v1`. Freeze all controls and thresholds listed above before profiles are opened. Preserve rejected alternatives and original rules. Missing dose/units, ambiguous route/system or an unlabelled change stops admission; a labelled change is exploratory. Human gate only for an interpretation-changing choice or separately proposed installation/transfer/host/compute boundary.

## 02-profile-qc

Accepted identity: profile table path/hash against frozen rule identities. Use the pack validator. Output: admitted `pk-nca-profiles-v1` and retained QC findings in coordinator artifacts. Check identities, bounds, schedule, units, finite/non-negative concentrations and censorship before fitting. Keep below-limit measurements censored even when substitution is frozen; never rewrite raw measurements. Refuse duplicate/non-monotonic times, missing identities/units and implicit zeros. Preserve failed controls and negative results; missing records are unavailable, never negative evidence. No additional human gate for valid offline fixtures.

## 03-subject-parameters

Accepted identities: unchanged rules and admitted profile paths/hashes. Use `compute_nca` via the validator. Output: per-subject portion of `pk-nca-report-v1` and `pk-nca-result-v1`.

Cmax is the maximum observed uncensored concentration; Tmax is its earliest measured time. No interpolation. Integrate from the first supplied observation (required to be time zero for AUC(0-tlast)) to the last quantified observation: linear trapezoids for increases, equal values or a zero endpoint; logarithmic trapezoids `(tb-ta)*(ca-cb)/log(ca/cb)` for positive decreases. A frozen substitute affects integration only; censored points never enter terminal fitting. No inferred pre-first-sample or post-last-sample area is added to measured AUC.

Fit log concentration against time by least squares on the exact frozen terminal times with positive quantified measurements. At least the frozen minimum points (and at least 3) are required. `lambda_z = -slope` must be positive. `adjusted_r_squared = 1 - SSE/SST*(n-1)/(n-2)`; zero variance is degenerate, never a convincing fit. `half_life = ln(2)/lambda_z`; `auc_0_inf = auc_0_tlast + Clast/lambda_z`; fraction is the added tail area divided by auc_0_inf. Equality to frozen fit/fraction thresholds is accepted. Too few points, low adjusted fit, zero variance, a nondecreasing slope or excess fraction produces explicit diagnostic reasons, unreliable half-life/AUC(0-inf) and group exclusion. Valid unreliable outputs are retained; pretending they are reliable is a labelled refusal. These thresholds are operational screens, never proof of an adequate elimination model.

## 04-group-summary

Accepted identities: unchanged rules/profiles and per-subject report. Use validator comparison. Output: group portion of `pk-nca-report-v1`. Compute `exp(mean(log(value)))` and [min,max] for each declared parameter over reliable subjects only, with n and included IDs. Preserve all excluded subjects and reasons in the subject table. n=0 produces unavailable summaries, never zero exposure. A zero Tmax gives an unavailable geometric mean with its range retained. No uncertainty interval or between-subject inference is estimated; do not imply one. No automatic dose normalization, clearance, volume or bioavailability is computed.

## 05-handoff and bounded claims

Accepted identities: complete rules/profile/report/evidence paths plus hashes and the returned `pk-nca-result-v1` captured by the coordinator. Use `$science-provenance` and coordinator-owned `$science-review` in record, source and method modes. Output: ordinary registered domain artifacts, separate existing claim entries and independent handoff; absent review remains unavailable. One checkpoint per run, ordered stage IDs. Review approval is never truth; association is never causality; computed agreement is never physical or clinical validity. Preserve negative results, unavailable evidence and failed controls.

The claim gate checks text regardless of the declared kind or status. Case-insensitive English whole-word prefix families with `\w*`: caus*, mechanis*, therap*, clinic*, efficac*, effective*, treat*, cure*, prevent*, recommend*, prescri*, bind*, affinit*, inhibit*, activat*, regulat*, drive/drives/driv*, induc*. Additional refused wording: truth, bioavailab*, safe dose, human exposure, exposure-response (space/hyphen), physical validity. This conservative lexical check includes negations and is incomplete for other languages or paraphrases. Empty support or any cited unavailable kind/result, including mixed citations, requires unavailable status. Unavailable text also cannot say supported, replicated, suggestive or significant. Positive statuses supported, suggestive and replicated cannot rely on computed or review-approval records (both kind AND result checked); replicated is always refused for these fixtures. Evidence/claim IDs and statuses must be strings before lookup. Boundary/evidence findings precede later numerical output or claim checks where their inputs are already admitted. Independent review and rigor classification remain outside this pack.

Frozen offline questions, acceptance criteria and budgets are in `benchmarks/workflow-pk-nca-profile/tasks.json`; each negative case in `examples/workflow-pk-nca-profile/negative-cases.json` has a named test checking its distinct refusal code. No installation, restricted transfer, new host, GPU/remote/heavy compute or publication is authorized.
